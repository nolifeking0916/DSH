# 第一项换题与全系列统一五级

三个测评模块的对外结论一律使用同一套五级（顶尖 / 优秀 / 良好 / 合格 / 待提升），每个模块给一个总档位、维度明细与短板提示；第一项由「16 型 + 四轴画像」换为「管理行为成熟度四维五档测评」——保留二极条目形式，但每题锚定"更有效的一端"计分，用绝对标准切档，整体档取最低维档。

之所以换题：原设计没有档位维度，16 型名称没有效度支撑且贴类型标签有公平性风险；之所以用绝对锚点而不是常模：本产品目前没有预试样本，没有参照分布就没有分位可依。

总报告给三项单项成绩，并在**档位层**（序数尺度）合成一个综合评估——因为三项的原始分数口径不同、不能相加，而五级是同一把尺；综合评估与「结构性偏科」提示只决定面试追问什么，同样不产生淘汰动作。

代价是失去"16 型画像"的直观标签与 144 条类型文案，换来的是三个模块口径一致、可辩护、且全系列不设淘汰线。

**修订（2026-10-25 13:02，维护者裁定）**：本 ADR 的两条被 [ADR-0010](0010-第一项不给整体档.md) 修订——

- 「总报告给三项单项成绩，并在档位层合成一个综合评估」一条**推迟**：产品里已实现的综合评估块先留着不动，推迟期间不作判读依据，等其余功能正常后再定。

其余内容不变（第一项换题的方向、绝对锚点而非常模、全系列不设淘汰线，都仍然有效）。

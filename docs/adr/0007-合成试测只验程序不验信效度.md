# 合成试测只验程序，不验信效度

在真人样本到位之前，可以用合成作答把试测的分析与判定程序先跑通一遍（生成样本 → 计分 → 统计 → 判定 → 打印验收）；但**由合成数据得出的任何数字都不作为信效度证据**：Cronbach's α、分半信度、分数分布、极端题比例，衡量的是生成模型的性质，不是题目的性质——生成时噪声设多大就有多大。

之所以要立这条：合成试测会产出一批看起来很像结论的数字（α = 0.74、四维分布、极端题清单），它们最容易被后来的人当成「题目已经验过了」，写进裁定表或对外材料。一旦写进去，第一项就会在没有任何真人证据的情况下看起来已经校准过。本产品的硬约束因此是：**零信效度证据不得进题库、裁定表与对外材料**；真人的信效度结论只能来自真人样本。

代价：真人样本到手前，所有关于第一项档位的表述都必须保留「绝对锚点口径，尚未校准」这句标注；模拟只能证明程序跑得动、报警报得准（例如 α 计算器在已知信度对照上排序与 0.70 分界都对，相关性检查弱相关不误报、强相关必报），证明不了题目好不好。

# 第一项不给整体档：性格测试只报四维各档与短板

第一项（管理行为成熟度四维五档测评）**不产出整体档（总档）**——施测人报告里第一项只给四维各自的分数与等级、标出短板维，外加倾向特征描述；第二、三项不变，仍给总档 + 维度明细 + 短板提示。五级仍用于第一项的**每一个维度**。

之所以取消：现行规则是「整体档 = 四维取最低维档」（短板决定）。在这条规则下，第一项整体档的顶端两档在结构上几乎不可达——要「优秀」得四维**同时** ≥18 分、要「顶尖」得四维**同时** ≥22 分；合成 n = 112 里两档各 0 人，只剩三档可报，四维同时 ≥22 分的联合概率约 2.7 × 10⁻⁷。这个门槛与真人分布无关，加样本不解决；票 #26 的校准（绝对锚点 → 参照分布切点）也只改每维切点、不改 min-of-4 这条合成规则，同样不解决。再叠加维护者原话——第一项是性格测评，本就不该给推荐性总档。取消之后，「整体档顶端档不可达」这个命题整体消失。

「综合评估」（三项在档位层合成）按维护者同一条原话**推迟**：产品里已实现的综合评估块先留着不动，等其余功能正常后再定撤留；推迟期间它不作为判读依据。

代价：失去「平均分掩盖单项塌陷」在第一项上的自动保护——现在只有短板维提示，不合成总档；第一项也不再有一个可供跨模块合成的单一等级，综合评估重启时合成输入口径需要重定。

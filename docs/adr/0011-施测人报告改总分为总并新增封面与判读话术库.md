# 施测人报告改「总→分→总」，新增封面页与判读话术库

维护者 2026-10-25 定：施测人报告不再是「总报告 + 三个模块报告」四段平铺，而是**封面页 + 总→分→总**——
先给总体画像（性格画像 → 本次作答的可信度 → 三类能力的总体表现），再逐项详评（每节带可信度），
最后回到整体评价（适合的方向、潜力、擅长与不擅长、面谈追问清单、使用边界）+ 附录；
报告里**不再出现「第N项」**，一律用人格特质 / 情景处理 / 逻辑分析能力。
**判读话术搬到云上数据库建后台**（`public.report_narrative`，按分数档 × 维度 × 特征极匹配后下发），
因为话术要能由维护者与 HR 直接改，而不必改代码发版。

理由：这份报告的唯一读者是施测人，他要的是「这个人整体什么样、哪里要追问」，
平铺的四段让他自己去拼；总→分→总把结论放在两端、明细在中间，读的顺序就是判读的顺序。
可信度单独成节，是因为「这份结果能不能信」和「这个人行不行」是两个问题，
混在一起时前者会被当成后者的依据。

**已知未决（各有后继票，勿在本 ADR 里当已定）**：
新类目名只落在报告侧，候选人知情文案与裁定表、词表仍用「第N项」（票 #50）；
成品内报告页与 `/hr/` 汇总台仍是旧渲染器，与生成器不同源（票 #49）。

# HR 业务资料档案工作约定

## 正本与资料边界

- 本仓只保存经策选、可长期保留、已脱敏的业务资料；原始工作区的原件、过程稿和证据不因此改变。
- 私有 Git 保存仓内资料版本，OpenViking 只保存允许在线检索的业务语义副本。
- 原 HR 工作区已有的定稿门、回执和审计要求继续有效；进入本仓不等于绕过秘书复核或维护者确认。
- 每篇迁移文档保留来源和迁移记录；不得捏造来源、日期、人数或口径。

## 安全红线

- 禁止写入或提交密钥、令牌、Cookie、数据库连接串、数据库原始导出。
- 禁止上传未脱敏人员明细、工号、薪级、薪酬个人信息及可复识别个人的组合信息。
- 不自动删除本地或云端内容，不自动把云端产出写回本仓。
- 不修改现有业务数据库、企业后台或企微原始数据，不自动对外发送任何内容。

## 变更与验收

- 业务资料修改必须可评审、可回读；提交前执行敏感信息检查和 `git diff --check`。
- 涉及在线检索副本时，必须核对 URI、检索命中和原文回读，不能把命令成功当作业务验收通过。
- 统一台账和展示由维护者确认的主文档承担，本仓不运行自动同步或智能体。

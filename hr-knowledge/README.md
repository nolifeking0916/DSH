# HR 业务资料档案（私有）

本仓保存 HR 数据中心已经策选、可长期保留的业务文档与定稿副本。原始工作区仍是原始证据和过程稿的留存位置；本仓不是业务数据库，也不是对外发布渠道。

## 保留内容

- `docs/`：制度正文、员工版、研究材料、证据说明与 Office/PDF 的文本语义副本。
- `assets/`：经策选的 Office、PDF 等原始附件。
- `outputs/`：后续定稿、会议材料与指定成果副本。
- `migration/`：迁移计数、暂缓迁移清单和完整性验收摘要。

## 使用边界

- 私有 Git 保存这些业务资料的版本；OpenViking 仅保存允许在线检索的业务语义副本。
- 密钥、令牌、数据库连接信息、数据库原始导出、未脱敏人员明细、工号、薪级及薪酬个人信息不得进入本仓。
- 业务数据仍以企业后台和 PostgreSQL 真源为准；“现行定稿”“审校通过”“维护者签发”“已发布”不得混称。
- 本仓不绑定桌面知识管理应用、自动同步器或智能体，不自动接收、删除或回写任何内容。

后续统一台账、任务和展示入口由维护者另行确认的主文档承担；本仓仅作为业务资料档案保留。

# 业务文档导航

本目录保存 HR 数据中心经策选和敏感信息检查、可长期保留的文档。原始工作稿、人员明细和证据原件仍留在原工作区。

## 迁移验收基线

- 策选源文件：160 件（第一批 87、第二批 73）。
- 已迁移源文件：147 件，生成 206 个仓内目标文件。
- 暂缓迁移：13 件；原因和完整源路径保存在仓外待审区，不进入在线副本。
- 本地独立验收：原始目标 162 件、Markdown 语义副本 44 件，哈希/正文回读通过；敏感扫描 0 命中，暂缓件泄漏 0 件。
- 后续定稿接收是独立批次，不能与首批 160 件混算；具体以 `migration/` 中保留的验收摘要为准。

## 目录

- `current/final/`：现行定稿的 Markdown 正文或语义副本。
- `evidence/final/`：与定稿配套的回执和来源说明。
- `current/employee/`：员工版正文。
- `current/ppt/`：已启用 PPT 的文本语义副本。
- `research/`、`working/`：已策选的研究和修订材料，不等同已签发制度。
- `extracted/`：Office/PDF 的可检索文本副本；原始附件在 `assets/`。

## 阅读口径

“现行定稿”“秘书审校通过”“维护者签发”“已发布”是不同状态，不能混称。具体以每份文件的回执和来源说明为准。业务数据仍以企业后台和 PostgreSQL 真源为准。

# 上下文注入

本仓库是「DSH 上下文注入」主题的独立归属地：插件源码、规格、决策记录、研究笔记与经验条目都在这里。

**注入源**：
把内容写进一轮对话上下文的通道；本仓库语境下指本地插件、内核块、工具结果这三类写入者。
_Avoid_：注入通道、供给方

**单一注入源**：
一种收敛状态——每轮只由一条注入源发出一条注入消息，且每类内容（经验 / 技能 / 记忆）只有一个供给路径。
_Avoid_：单源、唯一注入、单插件（都丢掉了「每轮一条消息」这层含义）

**注入预算**：
一次注入允许占用的字符上限；按内容分配额（经验 / 技能 / 记忆各一份），总预算再按比例缩放。
_Avoid_：字数限制、token 上限（预算含「怎么分」的语义）

**经验**：
本地 wiki 模式库里一条可复用做法的结论，注入时带原文件路径，模型可回读原文。
_Avoid_：规则、坑位、技巧（不含做法本身的沉淀）

**采纳率**：
注入条目在模型最终回答里被实际使用的比例；只证明相关性，不等于答案正确率提升。
_Avoid_：有效率、命中率

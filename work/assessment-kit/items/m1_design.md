# 第一项换题 · 题库设计与锚定方案

> 依据：`work/assessment-kit/统一五级裁定表_20261024.md` §2.1 / §2.2（票 #4 已结）；维护者 12:12 裁定「领域不变，可按核心理论设计题目」。
> 产物：`items/m1_items.json`（96 题，四维各 24）+ 四个维度分片 `m1_INT/SNT/TFS/JPS.json` + 合并脚本 `merge_items.py` + 三分类 `old96_classification.json`。

## 一、为什么换

原第一项是「16 型 + 四轴百分比」，**没有档位维度**，无法落到五级；16 型名称（建筑师等）没有效度支撑，且贴类型标签有公平性风险。维护者裁定：映射不到五级就换成同领域里可分五级的测评。

## 二、四维定义与理论依据

| key | 维度 | 测什么 | 核心理论出处 | 有效端判据 |
|---|---|---|---|---|
| INT | 互动方式 | 工作中与他人互动的能量方向与方式：主动把关系与协作推出去，还是先把事情理清再与人连接 | 荣格外向/内向维度 + 自我决定理论的关系需求 + 行为锚定等级 | **主动建立工作联系、把信息与协作推出去**的一端更有效；闷在自己这里等人来问的一端拖慢协作 |
| SNT | 关注重点 | 处理信息时的优先落点：先抓可核验的事实与细节，还是先抓整体趋势与可能性 | 荣格实感/直觉维度 + 系统思维「事实层—模式层—意义层」 | 在景区经营这类要落地、要对账的场景里，**先核事实再看趋势**更有效；只谈趋势不落事实容易做出兑现不了的判断 |
| TFS | 行事依据 | 判断与分歧时的落点：按讲清的道理与事先约定的标准，还是先照顾具体的人与关系 | 荣格思维/情感维度 + 目标定向理论（绩效规范 vs 人际支持规范）+ 程序公平理论 | 在规则明确、需一致执行的场景里，**先讲依据再谈处境**更有效；因人而异改判断在协作与交接上成本更高 |
| JPS | 行事节奏 | 安排与推进任务的节奏：先定顺序、按时收口，还是按当下状态随时调整 | 荣格判断/知觉维度 + 计划与执行分离 + 时间盒 + 情境领导 | 在多任务、强节拍、要对外交结果的场景里，**先排顺序、按时收口**更有效；想到哪做到哪更容易漏事 |

> 四个维度 key 与旧库四轴一一对应（EI→INT / SN→SNT / TF→TFS / JP→JPS），**领域不变**；变的只有出题方式与结论口径。

## 三、锚定判据与计分

- 每题二极强制对比，两侧是**行为频率陈述**；**一端是「更有效的一端」（anchor）**，选它记 1 分。
- 每维 24 题 → 0–24 分；按**绝对锚点**切五档：顶尖 22–24 / 优秀 18–21 / 良好 14–17 / 合格 9–13 / 待提升 0–8。
- **整体档 = 最低维档**（短板决定），报告页同时给出四维分与短板。
- 不设常模（目前没有预试样本，见「校准条件」）。

## 四、题目设计规则（合并脚本逐条机械校验）

1. 每维 24 题，共 96 题；id 唯一连续（INT-01…、SNT-01…、TFS-01…、JPS-01…）。
2. 每题 anchor ∈ {a, b}，**每维 a/b 条数差 ≤ 2**（实测四维均为 12/12）——防默认 acquiescence 偏差与位置偏置。
3. 两侧各 ≤ 20 字；全部为行为频率陈述；无重复题干。
4. 无双重否定；无 MBTI 字母标签；无智力/性格/临床词汇；不出现具体公司名、人名、地名。
5. 每题必须能说清「哪一端更有效」并给出理由（`rationale`）与依据（`theory`）。

机械校验入口：`python3 items/merge_items.py`（不通过即退出码非 0）。

## 五、现第一项 96 题的三分类

| 分类 | 数量 | 说明 |
|---|---|---|
| 可沿用 | 0 | 无一题可原样保留 |
| 需按新判据重写 | 96 | 旧库四轴与新四维一一对应，**主题全部在范围内**，情境素材可参考；但旧题按「两端都合理」的类型学出题，新判据要求每题有唯一有效端 → **表述与锚定要重做** |
| 不可用 | 0 | 无主题落在新四维之外 |

判定方式：每道旧题与新题库取最高字符 Jaccard 相似度，≥0.80 记可沿用、≥0.50 记需重写、其余因维度仍对应也计入需重写（明细见 `old96_classification.json`）。
**同时下线**：16 型名称与别名、144 条类型文案、四轴字母标签（E/I/S/N/T/F/J/P）。

## 六、标注与仲裁规程（真人试测阶段执行）

1. **双人独立标注**：两名标注员分别独立判断每题的「更有效的一端」，互不可见对方结果。
2. **分歧率门槛**：单题分歧记 1；某维分歧率 > 15%（即 24 题中 ≥ 4 题）→ **整维重标**。
3. **仲裁**：分歧题由测评负责人（HR 侧指定 1 人）仲裁，仲裁理由写回题库 `rationale`。
4. **锚定审计**：每维随机抽 6 题做反向审计（把有效端换到另一侧，问标注员是否还能选对），命中率 < 80% 的维度要重写题目。

## 七、试测与信效度方案（需真人样本，见另开票）

| 项目 | 方案 |
|---|---|
| 样本 | 内部候选人 30–50 份 + 在职员工 30 份（覆盖不同岗位层级） |
| 信度 | 每维 Cronbach's α ≥ 0.70，分半信度 ≥ 0.70；不达标的维度先合并维度再复测 |
| 岗位胜任力映射 | 四维分别对应哪些岗位胜任力（协作、计划、决断、复盘等），用 HR 绩效评语做定性校验；与第三项推理分做相关性检验（预期弱相关，若强相关需查题目重叠） |
| 施测条件 | 限时 90 分钟、独立作答、不设监考，与实际招聘条件一致 |
| 记录项 | 逐题作答时间（用于识别作答波动）、中途退出、复核申请 |

## 八、校准条件（从绝对锚点切到参照分布）

- 初版用**绝对锚点**（上表阈值），报告页明确标注「绝对锚点口径，尚未校准」。
- 累计 **≥ 100 份**有效作答后，按各维得分分布重算百分位切点，同步更新裁定表与成品阈值。
- 校准前**不得**按单个候选人的表现调阈值；阈值一旦定版写进留痕文件。

## 九、已知限制（如实记录）

1. **本文件是纯本地单文件，题库、答案与计分逻辑都在里面** —— 候选人能读源码看到答案。编码只用于防止计分出错，**不防人看答案**。施测需按规范执行（限时、独立作答），必要时用施测人现场发放的版本。
2. 绝对锚点尚未经真人样本校准，档位是「专家阈值」而非「人群分布」。
3. 四维的岗位胜任力映射尚未用绩效数据验证（依赖第七节的试测）。
4. 题面全部为行为频率陈述，**存在社会赞许偏差**（有人倾向选"看起来更专业"的一端）；题目对两端措辞做了等价化处理，但偏差只能靠试测观察，不能消除。

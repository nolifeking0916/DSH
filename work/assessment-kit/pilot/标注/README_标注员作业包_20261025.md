## 怎么填

- 每题只选 a 或 b（表里是下拉框）；拿不准也必须选一个，理由里写「两端都说得通 / 判据落不下来」——这种题正是我们要挑出来的。

- 时间：第一轮 96 题约 40–60 分钟；第二轮 24 题约 10–15 分钟。

## 四维判据（判断依据）

| 维度 | 定义 | 判据（哪一端更有效） |
|---|---|---|
| INT 互动方式 | 测量一个人在工作中与他人互动的能量方向与方式——是主动把关系与协作推出去，还是先把事情理清再与人连接。 | 在管理岗位上，能主动建立工作联系、把信息与协作推出去的一端更有效；把信息和决定闷在自己这里、等人来问的一端更容易拖慢协作。判据落在「先连接再推进」还是「先理清再等人」的工作顺序上，而不是讨不讨人喜欢。 |
| SNT 关注重点 | 测量一个人处理信息时的优先落点——是先抓可核验的事实与细节，还是先抓整体趋势与可能性。 | 在景区经营这类要落地、要能对账的管理场景里，先把事实与细节核清楚的一端更有效；只谈趋势与可能性、不落到可核验事实的一端容易做出兑现不了的判断；判据落在「先核事实、再谈趋势」的工作顺序上，而非细节永远比趋势重要。 |
| TFS 行事依据 | 测量一个人做判断与处理分歧时，依据先行还是人先行——是按讲清的道理与事先约定的标准，还是先照顾具体的人与关系。 | 在规则明确、需一致执行的管理场景里，先把依据与标准讲清楚、再处理具体人情的一端更有效；因人而异、因关系改判断的一端在协作与交接上成本更高。注意：不要写成"不顾人情"，要落在"先讲依据、再谈处境"这个工作顺序上。 |
| JPS 行事节奏 | 测量一个人安排与推进任务的节奏——是先定顺序、按时收口，还是按当下状态随时调整。 | 在景区运营这类多任务、强节拍、要对外交结果的场景里，先排顺序、按时收口的一端更有效；想到哪做到哪、一直开着的状态更易漏事。判定落在“先定顺序、留出弹性、按时收口”的工作顺序上，不等同于死板。 |

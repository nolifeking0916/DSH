## 一、这次真人试测要回答的 6 个问题

| # | 问题 | 判定阈值 | 不达标怎么办 |
|---|---|---|---|
| 1 | 每维的作答是否内部一致？ | 每维 Cronbach's α ≥ 0.70 且分半信度（Spearman-Brown 校正）≥ 0.70 | 先合并维度或补题，再复测；**不得**为了让 α 过线而删题（删题要留痕并复跑） |
| 2 | 标注员对「哪一端更有效」判断一致吗？ | 某维分歧率 ≤ 15%（24 题中 ≤ 3 题） | 该维**整维重标**（不是只改分歧题） |
| 3 | 把有效端换到另一侧，标注员还能选对吗？ | 每维抽 6 题，命中率 ≥ 80% | 该维题目重写；先重写「判据句没点到题面措辞」的那几题 |
| 4 | 四维对应哪些岗位胜任力？ | 每维至少 2 条胜任力，且能用 HR 绩效评语做定性印证 | 映射不成立的维要换题或改判据（对照票 #4 的裁定：映射不到五级就换同领域可分五级的测评） |
| 5 | 与第三项推理分是不是测了同一件事？ | \|r\| < 0.60（预期弱相关） | \|r\| ≥ 0.60 → 查题目是否重叠，重叠的题重写 |
| 6 | 题面是不是太露骨（社会赞许偏差）？ | 没有题目出现「≥ 90% 的人选同一端」 | 该题判据可能太露骨，重写 |

**另有两项贯穿全程**：

- **异常样本**：直线作答、全选锚定端、乱答、超快作答——必须先标记出来，不进信度统计。
- **校准**：累计 ≥ 100 份有效作答后，才允许把绝对锚点换成参照分布切点；**校准前不得按单个候选人的表现调阈值**。

## 二、样本与施测条件

### 样本

| 组 | 份数 | 分层要求 |
|---|---|---|
| 内部候选人（应聘 HR / 管理岗） | 30–50 | 覆盖不同岗位层级（专员 / 经理 / 总监），至少各 8 份 |
| 在职员工 | 30 | 至少覆盖 2 个部门 + 3 个岗位层级 |

- **有效作答定义**：96 题全作答、无中途退出、作答时长 ≥ 名义时长的 40%。
- 样本量到 **100 份**之前，任何阈值调整都只能写在「待校准」里，不得写进裁定表。

### 施测条件（与真实招聘条件一致）

- 限时 90 分钟（三项合计）、独立作答、不设监考。
- 作答设备为候选人自己的手机或电脑；**不联网、不上传**（单文件本地作答，数据只留本机）。

### ⚠ 两个必须提前知道的执行缺口

1. ~~**成品没有计时器。**~~ **票 #25 已修（2026-10-24）：成品现在有真倒计时。**
   首页勾「开启限时模式」后，从候选人点「同意并开始测试」那一刻起跑**一个 90 分钟钟**，
   答题页顶栏显示剩余时间（剩 10 分钟内转金色），到点**页面自动交卷**；
   未作答的题按未作答处理（不计入得分），结果 JSON 带「限时到点自动交卷」标记，
   施测人报告顶部会显示该标记 —— **这份结果没答完，不能当可比分数用**。
   ⇒ 施测侧仍要按规范控时（发卷记开始时刻），**两套并存**：页面到点会自己交卷，
   施测人也按统一时点收卷；页面先交卷的，以页面交卷时刻为准，并在记录表里注明。
   ⇒ **续答不重新计时**：候选人中途关掉页面再回来，时间继续走。

2. **成品不采集逐题作答时间。** 而逐题时间是**唯一能把「乱答」和「真实低分」分开的东西**
   （模拟已验证：乱答与低分者在只看第一项时不可区分）。
   ⇒ 本轮用**批次计时法**采集：候选人（或施测人）记录 96 题分 10 批的累计用时，
   录入时按每批题数折算成每题均毫秒（见 §五 登记表）。

## 三、施测须知

### 发卷前（施测人）

1. 用**现场发放**的方式给候选人：答案就在单文件源码里，编码只防计分出错，**不防人看答案**。
   远程发放必须配「限时 + 回收时点」两道约束（见上）。
2. 口头念一遍候选人须知（口径沿用《告知卡要素与数据留存规则清单》的 8 要素，**不得改写**）：
   - 这是什么、测什么、不测什么（不测性格、不测智力、不做医学或心理诊断）
   - 谁能看到结果（人力资源部 2–3 人，含用人部门负责人）
   - 结果不作为录用唯一依据
   - 结果只留本机，导出后由本人回传
   - 如对结果有疑问，可在 5 个工作日内提出复核
3. 记录发卷时刻（登记表「开始时刻」）。

### 作答中（施测人）

- 不提示、不解释题目、不回答关于题目内容的任何问题。
- 记录：中途退出时刻、复核申请（谁、何时、诉求）。
- 候选人问「答哪端都行吗」之类的问题，只回「按你真实的工作方式选就行」。

### 收卷时

- 到点收卷（90 分钟），记录收卷时刻与实际用时。
- 当场收回结果 JSON（候选人从页面导出的文件）。
- 确认文件里有 `tool / version / code / name / idLast4 / date / m1 / m2 / m3`。

## 五、双人标注与锚定审计

### 双人独立标注

1. 两名标注员分别独立判断每题的「更有效的一端」，**互不可见对方结果**。
2. 逐题记录：`题号 | 标注员 A 选择 | 标注员 B 选择 | 是否一致 | 仲裁结果 | 仲裁理由`。
3. 分歧率 = 分歧题数 ÷ 该维题数；**某维 > 15%（24 题中 ≥ 4 题）→ 该维整维重标**。
4. 分歧题由测评负责人（HR 侧 1 人）仲裁，仲裁理由写回题库 `rationale`（**裁决权在人，机器不代劳**）。

## 六、真实作答文件格式与复跑

把回收的作答整理成一个 JSON 文件（第一项只需 96 题的作答序列）：

```json
{
  "meta": { "note": "真人试测 2026-10-24" },
  "respondents": [
    {
      "id": "EQ-20261024-XXXXXX-XXXX",
      "group": "内部候选人",
      "responses": [0, 1, 0, 1, ...],
      "times_ms": [11000, 9500, ...]
    }
  ]
}
```

- `responses`：与题库 `items/m1_items.json` 的题目顺序一一对应；`0` = 选 a 侧，`1` = 选 b 侧；长度 96。
- `times_ms`：每题耗时（毫秒）。批次计时法录入时，按每批题数折算每题均毫秒。
- `id`：**不要写完整身份证号**，用测评编号或「后 4 位 + 编号」。

### 复跑命令

```bash
cd work/assessment-kit
node pilot/run_pilot.mjs pilot/out/real_samples.json          # 真实计分（同一段 report.js）
cp pilot/out/scored.json pilot/out/real_scored.json
python3 pilot/analyze.py --real pilot/out/real_samples.json \
        --scored pilot/out/real_scored.json \
        --exclude pilot/out/excluded_ids.json                 # 人工确认要剔除的异常样本
```

- `--exclude` 传一个 id 清单（JSON 数组或每行一个 id），剔除的样本**不进信度统计**，清单会写进 `analysis.json` 留痕。
- 真人模式下脚本会自动跳过「真值回收」与「α 自检对照」两项（合成数据专有）。

## 八、试测报告模板（骨架）

1. **样本**：各组份数、分层、剔除情况（剔除 id 与理由）
2. **信度**：每维 α / 分半信度 / 样本量 + 判定
3. **标注一致性**：每维分歧率 + 仲裁情况；锚定审计命中率
4. **分布**：每维分数分布（直方图 + 五级人数），**必须同时报分数分布，不能只报档位人数**
5. **题目质量**：极端题清单、判据句字面锚合度最低的题的双人标注结果
6. **胜任力映射**：四维 → 胜任力 → HR 绩效评语印证情况
7. **相关性**：与第三项推理分的 r
8. **异常样本**：检出清单与人工复核结论
9. **校准建议**（仅当 n ≥ 100）：参照分布切点候选 + 与绝对锚点的差异 + **是否定版的建议**
10. **修订建议**：题库改动清单（逐题，带理由与留痕）
11. **结论**：第一项是否可从「绝对锚点口径，尚未校准」升级

## 九、已知风险与缺口

1. **限时靠人工**：成品无计时器，90 分钟靠现场时点控制；远程发放时风险更高。
2. **作答时间靠人工采集**：批次折算后精度有限，异常判定的阈值必须在拿到真实时长分布后**重新标定**。
3. **答案在源码里**：必须现场发放 + 当场回收，或至少限时 + 统一回收时点。
4. **合成画像不等于 HR 群体**：模拟里的三档画像只是给合成作答注入真值的参数，
   真人试测不需要照搬，但它提醒一件事：**四维的岗位胜任力映射必须用真实绩效评语校验**，
   不能靠设计者自己的判断（见验收条款 4）。
5. **校准样本量**：内部试测量（60–80 份）**达不到** 100 份校准门槛，
   第一轮只能出「信度与题目质量结论」，校准要等样本累积到 100 份。

## 二、本轮能下什么结论、不能下什么结论（限定语 · 必写）

> 下面这段是**必填的正文**，不是备注。它照《信度结论写法_三选一_20261025.md》§2.1（A 案）的句式改写，留空处按本轮实际数填。
> **限定语清单一条都不能少**：① 区间；② n 与 k；③ 半宽或「这条线落在区间内部」；④ 复核时点 253。

> **本轮能下的结论**：
>
> - 每维内部一致性的**量级**（Cronbach's α 的点估计与 95% 区间、分半信度 SB 的点估计与其区间），以及题目质量层面的**筛查清单**（分歧题号、锚定审计命中数、极端题号）。
> - 四维分数分布与五级人数的**描述性**结果（每维分位、均值 SD、各档人数）。
>
> **本轮不能下的结论**：
>
> - 任何「达标／不达标」的**点判定**。理由：在 n = 〈n〉 时，α 的 95% 区间半宽为 〈半宽〉，「α = 0.70」这条线**落在区间内部**（〈下界〉 < 0.70 < 〈上界〉）；点估计 〈α̂〉 与 0.70 的差距（〈差〉）**不足区间半宽的一半**。据此写「达标」或「不达标」都是把噪声当结论。
> - 任何「整体档优秀/顶尖不可达」的断言（**第一项已无总档**，ADR-0010；那是旧规则「整体档 = 四维取最低」的结构性性质，与真人分布无关，随总档取消整条命题消失）。
> - 任何把**五级人数**作为对外结论的说法（端点档占比未知，样本量不足）。
> - 任何**校准切点**（见 §九）。
>
> **复核时点**：本报告所列各维列入**复核清单**，**累计有效样本达到 253 份后重判**（此时区间半宽 ≤ 0.05）。
>
> **口径出处：**《信度结论写法_三选一_20261025.md》§2.1（四条限定语）、§7.1 A 版；《样本量与信度推断边界_20261025.md》§1.2（半宽反解：≤0.05 → n ≥ 253）、§6.1 C1–C3、§6.3。

## 三、每维信度（INT / SNT / TFS / JPS 各一节）

### 3.0 通用判读规则（四维相同，先读这一段）

1. **口径**：每题按锚点对齐后计分（1 = 选了更有效的一端），α = Cronbach's α；分半 = 奇偶分半 + Spearman-Brown 校正（pilot/analyze.py:328–352）。**不按锚点对齐直接算会得到垃圾数（α 全部为负），且不会报错**（《样本量与信度推断边界》§2.3 第 3 条）。
2. **α 的 95% 区间**用 Feldt 型解析式（下界 = 1−(1−α̂)·F₀.₉₇₅(n−1,(n−1)(k−1))，上界 = 1−(1−α̂)·F₀.₀₂₅(n−1,(n−1)(k−1))，k = 24）【解析】（《样本量与信度推断边界》§1.2；pilot/analyze.py --selftest-ci 会复现该表）。
3. **分半 SB 的区间没有解析公式**（Charter 2000 全文未取得）⇒ **只能由重抽样给出**（《样本量与信度推断边界》§7.4 第 9 条；《信度结论写法》§2.1 第 2 行、§8.3 第 4 条）。
4. **判读行只有三种写法**：
   - 区间**整段 > 0.70** → 「该维内部一致性**稳健达标**」（C3）；
   - 区间**整段 < 0.70** → 「该维内部一致性**明显不足**，需补题或合并维度后复测」（C2）；
   - 区间**跨线**（含端点落在 0.70 上） → 「**跨线·不确定**」，本轮不判定，列入复核清单。
   - 口径出处：《样本量与信度推断边界》§1.4、§6.1 C1–C3；A 案写法见《信度结论写法》§2.1、§7.1。
   - **写法切换**：3.1 里那句「**本轮不判定该维达标与否**」是「跨线·不确定」时的写法。若该维判读为「稳健达标」或「明显不足」，把该句替换成对应结论（「该维内部一致性稳健达标」／「该维内部一致性明显不足，需补题或合并维度后复测」），**并保留**区间、n、k 与复核时点（253）这几处限定语；其余三维同此规则。
5. **【解析】门限表**（观测 α̂ 要多高，才算「整段在 0.70 同一侧」；k = 24；**引用时必须带 n 与 k**）：

   | n | 要说「整段 > 0.70」需 α̂ ≳ | 要说「整段 < 0.70」需 α̂ ≲ |
   |---|---|---|
   | 60 | 0.7864 | 0.5509 |
   | 80 | 0.7770 | 0.5767 |
   | 100 | 0.7703 | 0.5931 |
   | 200 | 0.7524 | 0.6297 |
   | 300 | 0.7438 | 0.6443 |
   | 500 | 0.7348 | 0.6581 |

   > ⚠️ 「之下」那一列**经过勘误更正**（《样本量与信度推断边界》2026-10-25 勘误节）：原值（0.587 / 0.603 / 0.614 / …）**复现不出来**，现已改为按 §1.2 解析式重算的 0.5509 / 0.5767 / 0.5931 / … 。**引用一律用本表**。
6. **α 与分半不是两份独立证据**（Cronbach 1951：α 是全体二分切法的平均）；真实 α 接近阈值时两者「一个过一个不过」的冲突率可达 **15%–24%**（n = 60）⇒ **冲突时以 α 为准，该维记「待复核」，不据此改题**（《样本量与信度推断边界》§2.1/§2.2/§2.3；《信度结论写法》§3.5、§7.1）。
7. **标准依据**：标准 2.19 明确「只报一个点值（如 α = 0.90）是不可接受的」（p.47）；标准 2.3 注释要求**分维**报信度（p.43）；标准 2.6 要求不同误差定义的系数**不得互换解读**（p.44）。

- **每档人数的抽样误差**与**一个人被判到哪一档的测量误差**是两层，n 只能改善前者。分类的**重测一致性**在推演下约 87%–89%，**不随 n 改善**（《样本量与信度推断边界》§3.4）；标准 2.16（p.46）要求分类决策时报「两次施测分类一致的比例」。

### 5.3 社会赞许偏差（≥ 90% 同端）

| 题号 | 维 | 同端人数/作答人数 | 同端率 | Wilson 95% 区间 | 触发的判据句（原文） | 结论 |
|---|---|---|---|---|---|---|
| | | | | | | ☐需复核（人工读） ☐不触发 |

- **只作筛查信号，不作结论**：把触发结果写成「**触发题号 + 每题同端率 + Wilson 95% 区间**」，**不要**直接写「该题判据太露骨 → 重写」（《样本量与信度推断边界》§5.1）。
- **为什么**：观测到 90% 时，真实同端率的 95% 区间（Wilson）在 n = 60 时是 **[0.799, 0.953]**、n = 80 时是 **[0.815, 0.948]**【解析】——也就是**五个人里就有一个真的不同意**。这类题要不要改、改的是「题面措辞」还是「判据句」，要靠标注反馈，不靠这一条比例。
- **跨轮次比较无效**：该判据的灵敏度随 n 增大而**下降**；真同端率恰为 0.90 时，触发概率恒在 50% 上下 ⇒ **不同批次的「触发题数」不可横向比较**（《样本量与信度推断边界》§5.1 第 3 条）。
- **若要写成带推断的判定**：可写「该题同端率的 Wilson 下界 > 0.85」这类形式，**并在报告里写明用的是哪个形式**（《样本量与信度推断边界》§5.1 建议）。〔本项目尚未裁定采用哪种形式 —— **待定（维护者裁定）**；建议：本轮仍用「触发 + 区间 + 需复核」的筛查写法。〕
- **口径出处：**《样本量与信度推断边界》§5.1、§6.1 C5；《真人试测作业包》§一第 6 问、§七。

## 九、校准（三道关，写法随 n 变）

| 累计有效 n | 本轮处于 | 本节允许写什么 | 明确不能写什么 |
|---|---|---|---|

**固定写法（三档各自的正文）：**

- **n < 100**：「本次复测的档位仍为**绝对锚点口径，尚未校准**。累计有效样本 〈n〉 份，未达 100 份的候选切点门槛，因此**本报告不给出任何参照分布切点**。」（依据：待确定清单 D2；docs/adr/0007-合成试测只验程序不验信效度.md）
- **100 ≤ n < 300**：「累计有效样本 〈n〉 份，已达**候选切点**门槛。以下参照分布切点为**候选值、未定版**，**不得写进裁定表、不得对外作为阈值**；与绝对锚点的差异见下表。」〔附：候选切点 vs 绝对锚点对照表〕
- **n ≥ 300**：「累计有效样本 〈n〉 份，各维分位切点的 95% 取值范围 ≤ ±1 分，**参照分布切点可以定版**（定版须留痕，见《统一五级裁定表》§6『阈值一旦定版写进留痕文件，之后不得按人调阈值』）。」

**两条纪律：**

1. **校准前不得按单个候选人的表现调阈值**（items/m1_design.md 第八节）。
2. **无论 n 多大，都要报「两次施测分类一致的比例」**（标准 2.16，p.46）—— 这一项**不随 n 改善**（《样本量与信度推断边界》§4.3、§3.4）。

> ⚠️ 「100 份」是**工程约定，不是标准或文献给出的最小样本量**（《样本量与信度推断边界》§4.2、§7.5）：《Standards》(2014) 只要求「报告信度研究的方法与样本量」（标准 2.19，p.47）与「样本量足够」（标准 4.10，p.88–89），**从未给出任何最小样本量数字**。

## 附 A：防误用清单（照《试测报告_模拟版_20261024.md》§四 的写法）

> 写在这里，是为了以后有人翻到这份报告时，不会把它当成信效度证据。

- ❌ **不能把 α̂ 的点估计当成信效度证据**。区间必写、n 与 k 必写（《Standards》标准 2.19，p.47；Kennedy 2022：信度应报区间而非点值）。
- ❌ **不能写「α ≥ 0.70 达标」**（n 未到 253 份时）。点判定在阈值恰落在真值上时通过概率约 0.55，且**加样本量不改善**（《样本量与信度推断边界》§1.3/§1.4）。
- ❌ **不能把「α 过了、分半也过了」当成两次独立验证**（α 是全体二分切法的平均，Cronbach 1951）。两者判定冲突率可达 15%–24%。
- ❌ **不能把任何合成数据上的数字写进这份报告**。合成数据上的 α、分布、极端题比例是**生成模型的性质**，不是题目性质（docs/adr/0007-合成试测只验程序不验信效度.md）。
- ❌ **不能把端点档（各维的顶尖/优秀）的人数作为对外结论**；第一项已无整体档（ADR-0010），「整体档优秀/顶尖不可达」这条命题随总档取消**整体消失**，不得再被当成任何结论的依据。
- ❌ **不能写「该题判据太露骨 → 重写」**。≥ 90% 同端只作筛查信号，要写题号 + 同端率 + Wilson 区间 + 「需复核」。
- ❌ **不能把锚定审计的 6 题命中率说成「该维整体锚定质量」**。这 6 题是最难锚合的有偏抽样；「通过」只能读作「最难的那些题也没崩」。
- ❌ **不能把一致率当信效度证据或信度指标**。一致率只是收敛性证据（方案 §四、§六）。
- ❌ **不能因为 |r| 的区间跨过 0.60 就写「测的是同一件事/不同东西」**。
- ❌ **不能把第 13 条的两个数（完成整卷比例 / 省略作答比例）当信度证据** —— 它们是施测条件的证据。
- ❌ **不能把本报告当成「验收通过/不通过」的判决书**。第一轮的产出是「一份带区间的信度与题目质量诊断报告」（《样本量与信度推断边界》§6.3）。
- ❌ **不能把「未执行」的条款留空**（第 10 条未执行时要写明「未执行」与原因）。
- ❌ **不能对外引用**：任何个人分数、任何档位人数占比、任何候选切点、任何矛盾案例原文。本报告是**内部文件**；对外书面反馈只报 4 个合并维度 + 总档 + 「辅助参考，不作录用唯一依据」（《统一五级裁定表》§3；《告知卡要素与数据留存规则清单》§2.4 红线）。
- ❌ **不能按单个候选人的表现调阈值**（items/m1_design.md 第八节）。

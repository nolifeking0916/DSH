# 信度结论写法三选一（票 #29 决策材料）

> **一句话结论**：三个选项在第一轮 n = 60–80 下**没有一个能拿到"真结论"**——A 只是不判，B 把「点判定在阈值上功效约 0.5」这个结构问题换了个位置（阈值从 0.70 挪到 T，等效观测门槛随之从 α̂ ≳ 0.70 变成 α̂ ≳ 0.70/0.72/0.74，见 §3.1），C 保留点判定但必须承认它会在约 45% 的边界维度上误杀；**因此建议选 C 并强制采用 A 的报告写法（区间必写、判定必带限定语），把 B 推迟到累计 n ≥ 253（区间半宽 ≤ 0.05）之后一次性定版**——届时若维持"真 α > 0.70"的质量主张需 n ≥ 367（观测 α̂ = 0.74 时），若接受 T = 0.62 一类折中则 n ≈ 300 即可（等效门槛 α̂ ≳ 0.676），但那等于自觉把质量主张下调，**必须由维护者明确拍板，不在本文件的决定权范围内**。

## 2. 三个选项的报告长什么样（可直接抄的模板句）

### 2.0 统一的假设场景（**假设值，不是实测**）

> **【假设】** 下面所有模板都跑在同一个假设场景上：**某维在 n = 80 的真人样本上，观测 α̂ = 0.74，分半 SB = 0.71，k = 24。**
> α 的 95% 区间按 §1.2 的解析式算得 **[0.650, 0.816]**（区间半宽 **0.083**）【解析】。
> （n = 60 时同场景为 [0.635, 0.826]；n = 300 时为 [0.696, 0.781]【解析】。）

**为什么选这个场景**：α̂ = 0.74 是**点判定会判"达标"、区间判定会判"跨线不确定"**的那一档——三份模板的差别在这里才看得出来。

### 2.1 A（描述式）——报告里逐字这么写

> **信度（第一轮，n = 80）**
>
> - 本维 Cronbach's α = **0.74**，95% 置信区间 **[0.650, 0.816]**（n = 80，k = 24）。
> - 本维分半信度（Spearman-Brown 校正）= **0.71**，95% 置信区间 **[待填：须由重抽样给出]**（n = 80，k = 24；本项目尚无可用的分半信度解析区间公式——Charter 2000 全文未取得，见笔记 §7.4 第 9 条）。
> - **本轮不判定该维达标与否。** 理由：n = 80 时 α 区间半宽为 0.083，「α = 0.70」这条线落在区间内部（0.650 < 0.70 < 0.816）；点估计 0.74 与 0.70 的差距（0.04）**不足区间半宽的一半**，据此写"达标"或"不达标"都是把噪声当结论。
> - 该维列入**复核清单**：累计样本达到 253 份后重判（此时区间半宽 ≤ 0.05）。

**模板里的限定语清单（一个都不能少）**：① 区间；② n 与 k；③ 半宽或"这条线落在区间内部"；④ 复核时点（253）。

### 2.2 B（区间判据）——报告里逐字这么写

> **信度（第一轮，n = 80）**
>
> - 本维 Cronbach's α = **0.74**，95% 置信区间 **[0.650, 0.816]**（n = 80，k = 24）。
> - 判定（区间判据，阈值 **T = 0.62**）：区间下界 **0.650 > 0.62** ⇒ 本维**达标**。
>   本判据的含义是：**以 95% 置信度可以说真实 α > 0.62**；它**不**声称真实 α ≥ 0.70。
> - 本维分半信度（Spearman-Brown 校正）= **0.71**（n = 80，k = 24），本轮仍按点估计记录（该系数暂无区间公式）。
> - **α 与分半判定冲突时以 α 为准，该维记为「待复核」，不据此改题**（冲突率可达 15%–24%，笔记 §2.2）。

**同一个场景，换三个 T 会得到三种判定**（下界 0.6502）：

| T | 判定 | 该阈值在 n = 80 等效于观测 α̂ ≳ | 备注 |
|---|---|---|---|
| 0.60 | **达标**（0.6502 > 0.60） | 0.7027 | 等效门槛 ≈ 现行点判定；**但声明的质量下界只有 0.60** |
| 0.62 | **达标**（0.6502 > 0.62） | 0.7176 | 比现行的 0.70 更严 |
| 0.65 | **达标，但压线**（0.6502 > 0.65，差 0.0002） | 0.7399 | α̂ 差 0.001 就翻面 ⇒ **报告里必须写区间，不能只写"达标"** |
| 0.70 | **不达标**（0.6502 < 0.70） | 0.7770 | 第一轮几乎不可能通过（见 §3.2） |

### 2.3 C（维持点判定 + 强制功效声明）——报告里逐字这么写

> **信度（第一轮，n = 80）**
>
> - 本维 Cronbach's α = **0.74 ≥ 0.70**，判定**达标**；分半信度（Spearman-Brown 校正）= **0.71 ≥ 0.70**，判定**达标**（n = 80，k = 24）。
> - 同一维 α 的 95% 置信区间为 **[0.650, 0.816]**（区间半宽 0.083）。
> - ⚠️ **功效声明（必写，不得删改）**：「本条以点估计 α̂ ≥ 0.70 判定。在 n = 60–80 的样本量下，该判据在阈值恰好落在真实 α 上时（真实 α = 0.709）的通过概率约为 **0.55**（n = 60/80/100 分别为 0.552/0.564/0.577），**且不随样本量改善**（n = 300 时为 0.578）；真实 α = 0.683（略低于阈值）时仍有 **0.386/0.375/0.399** 的概率被判为达标。**因此本判定只作线索，不构成「该维质量合格」的结论。**」

**模板里的限定语清单**：① 固定功效声明（逐字，每次一样）；② 区间；③ n 与 k；④ 一句"只作线索"。

## 3. B 方案：新阈值定多少、依据是什么

### 3.1 判据形式与它的"等效观测门槛"

B 的判据写出来是：**「α 的 95% 置信区间下界 > T」**。这条判据在给定 n 下，等价于要求观测到的 α̂ 高过某个门限（因为区间下界对 α̂ 单调增）：

| T（声称的质量下界） | n = 60 | n = 80 | n = 100 | n = 300 |
|---|---|---|---|---|
| 0.60 | α̂ ≳ 0.7152 | α̂ ≳ **0.7027** | α̂ ≳ 0.6937 | α̂ ≳ 0.6584 |
| 0.62 | α̂ ≳ 0.7295 | α̂ ≳ **0.7176** | α̂ ≳ 0.7091 | α̂ ≳ 0.6755 |
| 0.65 | α̂ ≳ 0.7508 | α̂ ≳ **0.7399** | α̂ ≳ 0.7320 | α̂ ≳ 0.7011 |
| 0.70 | α̂ ≳ 0.7864 | α̂ ≳ **0.7770** | α̂ ≳ 0.7703 | α̂ ≳ 0.7438 |

【自算：笔记 §1.2 解析式反解】

**这张表是本文件最重要的一张表**，它说明三件事：

1. **T = 0.60 在 n = 80 时几乎就是现行的 α̂ ≥ 0.70**（0.7027 vs 0.70）——但它声称的质量下界只有 **0.60**：我们实际在说"这个维度的真实 α 可能只有 0.61，我们接受"。
2. **T = 0.62 / 0.65 / 0.70 在 n = 80 比现行判据更严**（分别要 α̂ ≳ 0.7176 / 0.7399 / 0.7770）。**换判据形式不等于放松判据**：第一轮若用 B，触发"补题/合并"的维会**变多**。
3. **门槛随 n 漂移**：同一个 T 在 n = 60 与 n = 300 之间移动 0.05–0.07。⇒ **若采用 B，条款里必须同时写明 T 和"在哪个 n 档启用"，否则同一份题库在不同批次会得到不同判定。**

### 3.2 「阈值 × 所需 n」对照表（本文件要的那张）

读法：**在观测到 α̂ = X 的情况下，要让 95% 区间的下界超过 T，至少需要多少份样本。**

| 观测 α̂（假设） \ 阈值 T | 0.60 | 0.62 | 0.65 | 0.70（维持"真 α > 0.70"） |
|---|---|---|---|---|
| **0.70** | 86 | 130 | 315 | —※ |
| **0.72** | 55 | 76 | 146 | 1 632 |
| **0.74** | 37 | 48 | 80 | **367** |
| **0.76** | — | — | — | 146 |
| **0.78** | — | — | — | 73 |

【自算：笔记 §1.2 解析式，k = 24；"所需 n"= 区间下界首次超过 T 的最小 n】

※ 观测 α̂ = 0.70 时，"下界 > 0.70"要求无限增大样本——因为观测值恰好落在阈值上，区间永远跨线。

**同一张表的另一读法（更实用）**：把"需要多大 n"换成"能撑住多大的门槛主张"——

| 想要声称的东西 | 在 n = 80 | 在 n = 300 |
|---|---|---|
| 真 α > 0.60（等效门槛 ≈ 现行 0.70） | 可行（需 α̂ ≳ 0.7027） | 可行（需 α̂ ≳ 0.6584） |
| 真 α > 0.62 | 可行（需 α̂ ≳ 0.7176） | 可行（需 α̂ ≳ 0.6755） |
| 真 α > 0.65 | 压线（需 α̂ ≳ 0.7399） | 可行（需 α̂ ≳ 0.7011） |
| 真 α > 0.70（**不降质量主张**） | **不可行**（需 α̂ ≳ 0.7770） | 需 α̂ ≳ 0.7438 |

### 3.3 三条线分别意味着什么（0.60 / 0.62 / 0.65）

| T | 这条线**实质**上在说什么 | 优点 | 代价 | 什么时候能用 |
|---|---|---|---|---|
| **0.60** | "真实 α 的下界能守住 0.60" | 第一轮就有方向性结论；等效门槛 ≈ 现行判据（α̂ ≳ 0.7027），**不额外冤枉合格维** | **质量主张减半**：接受真实 α 可能只有 0.61 的维度；k = 24 的 24 题量表，α = 0.61 属于弱内部一致性 | n = 80 即可，但**必须在报告里写明"本判据不主张真 α ≥ 0.70"** |
| **0.62** | "真实 α 的下界能守住 0.62" | 与 0.60 差不多松紧，但**门槛更有心理锚点**（0.62 是 0.60 与 0.65 之间的折中，且接近现行 0.70 的"一半折扣"） | 同 0.60：质量主张低于 0.70；且 n = 80 时等效门槛 α̂ ≳ 0.7176，**比现行判据严**，第一轮触发补题的维更多 | n ≈ 80 可用；**n ≥ 253 后最稳**（等效门槛 α̂ ≳ 0.676） |
| **0.65** | "真实 α 的下界能守住 0.65" | 质量主张比 0.60 高 | n = 80 时等效门槛 α̂ ≳ 0.7399，**明显严于现行判据**；真 α = 0.71 附近的维第一轮几乎全判不达标 | **建议 n ≥ 300 后再启用**（等效门槛 α̂ ≳ 0.7011，与现行判据相当） |

**结论**：**第一轮用 B，T 只能取 0.60（否则会放大补题量），但 T = 0.60 等于把质量主张从 0.70 降到 0.60；B 的"不降低质量主张"版本（T = 0.70）需要 n ≥ 367。**

### 3.4 B 真的解决"功效约 0.5"了吗？（关键对照）

用**正态近似**（α̂ ~ N(真 α, SD)，SD 取笔记 §1.3 的推演值）算各判据的通过率【自算：解析式 + 笔记 §1.3 的 SD；正态近似，非蒙特卡洛】：

**n = 80**（第一轮典型样本量）

| 真实 α | 现行 α̂ ≥ 0.70 | 下界 > 0.60 | 下界 > 0.62 | 下界 > 0.65 | 下界 > 0.70 |
|---|---|---|---|---|---|
| 0.810 | 0.990 | 0.989 | 0.975 | 0.932 | 0.758 |
| 0.792 | 0.962 | 0.957 | 0.924 | 0.842 | 0.613 |
| 0.772 | 0.885 | 0.876 | 0.818 | 0.704 | 0.467 |
| 0.753 | 0.811 | 0.799 | 0.723 | 0.587 | 0.344 |
| 0.732 | 0.700 | 0.684 | 0.593 | 0.449 | 0.230 |
| **0.709**（刚过线） | **0.556** | 0.539 | **0.447** | 0.315 | 0.144 |
| 0.683（差一点不过线） | 0.404 | 0.389 | 0.311 | 0.208 | 0.090 |

**读法（这一节决定推荐）**：

- **B 没有解决"边界处功效约 0.5"**——它只是把边界挪到了 T：T = 0.62 时，真 α = 0.709 的通过率是 **0.447**，**比现行的 0.556 还低**。
- T = 0.60 时通过率与现行判据几乎一样（0.539 vs 0.556）——**判别力没变，只是把声称的质量下界从 0.70 降到了 0.60**。
- 真正的分水岭在 n：**n = 300** 时，T = 0.62 的通过率在真 α = 0.709 处是 **0.700**、真 α = 0.683 处是 **0.543**；T = 0.65 是 0.549 / 0.398。**边界处的判别力随 n 变好，换判据形式不变。**

**⇒ 第一轮的问题不是"判据形式不对"，是"样本量不够下判定"。三个选项谁都没绕开这一点。**

### 3.5 分半信度那一半：B 用不上

- 本项目**没有可用的分半信度区间公式**（Charter 2000 全文未取得，笔记 §7.4 第 9 条）；分半的区间只能由**重抽样**给出。
- α 与分半**不是两份独立证据**（Cronbach 1951：α 是全体二分的平均），两者判定冲突率 15%–24%（笔记 §2.2）。
- ⇒ **无论选哪个选项，条款里都必须加一句"α 与分半冲突时以 α 为准并记为待复核，不据此改题"**。否则第一轮会出现"α 过了、分半没过 → 补题"的连锁动作，而其中约 1/4 是纯噪声。

## 4. 每个选项的风险与代价

### 4.1 A（描述式）

**风险 1：放弃"不达标就不动"的护栏。** 现状第 7 条的护栏是"α̂ < 0.70 → 先合并维度或补题再复测"。A 若不补护栏，**连"明显不一致"的维都不会被拦下**——这是质量风险（不是统计风险）。

> **建议补的护栏（可辩护的版本）**：**「某维 α 的 95% 区间整段落在 0.70 之下」才触发「合并维度或补题再复测」**（即笔记 §6.1 的 C2 规则）。这条护栏的触发门限【自算，笔记 §1.2 解析式】：

| 护栏：区间整段 < T | n = 60 | n = 80 | n = 100 | n = 300 |
|---|---|---|---|---|
| 整段 < 0.70（建议用这条） | α̂ ≲ 0.5509 | α̂ ≲ **0.5767** | α̂ ≲ 0.5931 | α̂ ≲ 0.6443 |
| 整段 < 0.65 | α̂ ≲ 0.4761 | α̂ ≲ 0.5062 | α̂ ≲ 0.5252 | α̂ ≲ 0.5850 |
| 整段 < 0.60 | α̂ ≲ 0.4012 | α̂ ≲ 0.4356 | α̂ ≲ 0.4574 | α̂ ≲ 0.5258 |
| 整段 < 0.55 | α̂ ≲ 0.3264 | α̂ ≲ 0.3651 | α̂ ≲ 0.3896 | α̂ ≲ 0.4665 |

**这条护栏的误报率极低，但漏报真实问题**【自算：正态近似 + 笔记 §1.3 SD，n = 80】：

| 真实 α | 0.81 | 0.772 | 0.753 | 0.732 | 0.709 | 0.683 | 0.65（外推） | 0.60（外推） |
|---|---|---|---|---|---|---|---|---|
| P(区间整段 < 0.70) | 0.000 | 0.001 | 0.002 | 0.005 | 0.019 | 0.064 | 0.164 | 0.390 |

⇒ 真 α ≥ 0.75 的维几乎不会被误判（≤0.2%）；但真 α = 0.65 的维第一轮只有 **16%** 会被拦下、真 α = 0.60 的维只有 **39%**。**这就是 A 的代价：护栏保住了"不冤枉好题"，但"抓住真差的题"这一半很弱。**

**风险 2：第一轮拿不到"验收结论"。** 票 #26 的第 7 条在第一轮**无法闭环**——要么延期到 n ≥ 253，要么明确写"第一轮只出描述，信度验收结论延后"。这需要维护者接受票 #26 的进度拆分。

**风险 3：读者会自己脑补结论。** 只写 α̂ = 0.74 不写"这条线落在区间内部"，多数读者会自动读成"过了"。⇒ 模板里必须写全 §2.1 的四条限定语。

### 4.2 B（区间判据）

**风险 1：阈值一旦定版就成了事实标准。** T 会同时出现在票 #26 第 7 条、`pilot/真人试测作业包` §七阈值表、`pilot/analyze.py` 的常量里，三处任一漏改就会**口径分裂**。

> **建议的维护机制**：
> ① **单一来源**：T 只写在 `pilot/analyze.py` 的常量旁（与 `ALPHA_MIN` / `SPLIT_MIN` 同处），其余两处引用它；
> ② **改 T 必留痕**：任何修改须在本票留一行"改前 → 改后 + 依据 + 生效的 n 档"，并注明"由谁在何时改"；
> ③ **写明性质**：条款里注明「T 是本项目自定的政策阈值，**不是任何测量标准给出的数字**」（笔记 §7.5：标准与文献都没有给出信度的最小样本量或阈值依据）；
> ④ **绑定 n 档**：T 只在指定 n 档启用（如"n ≥ 253 后启用 T = 0.62"），避免门槛随 n 漂移（§3.1）。

**风险 2：等效门槛会漂移。** 同一 T 在 n = 60 与 n = 300 之间移动 0.05–0.07（§3.1）——不写 n 档就会出现"同一批题，样本多时反而判不达标"的怪事。

**风险 3：定得低 = 质量主张下调。** T = 0.60 时我们实际在声明"真实 α 可能只有 0.61 也接受"。**这必须是一个自觉的选择并写进条款**，不能默认。

**风险 4：第一轮用 B 会放大补题/合并的动作量。** T = 0.62 在 n = 80 时等效门槛 α̂ ≳ 0.7176，真 α = 0.709 附近的维通过率只有 0.447（§3.4）——**比现行判据更容易触发"不达标"**。⇒ 第一轮直接上 B = **放大"对噪声动手"的风险**，正是票 #29 第 2 条担心的那件事。

**风险 5：分半那半用不上同一套判据**（§3.5），条款会出现"一半有方向、一半没有"的不对称。

### 4.3 C（维持点判定 + 功效声明）

**风险 1：每份报告都要带功效声明，读者理解成本高。** 同一句话在多份报告里重复；而且"0.55"这个数**极易被误读**成"这套题有 45% 概率不合格"——它其实是"阈值恰好落在真值上时"的**边界性质**，与题库好坏无关。

> **缓解**：① 声明写成**固定的一段、逐字复制**，不做个性化改写；② 声明里同时写"真实 α ≈ 0.68 时仍有 0.38 的概率被误判为达标"（两个方向都写），避免单边印象；③ 声明旁边必须同时给区间（§2.3 的模板已如此设计）。

**风险 2：误判仍在，处置动作仍可能对噪声动手。** 真 α ≈ 0.71 的维第一轮有约 **45%** 被判"不达标"（0.556 通过率），而现行条款会直接触发"合并维度或补题再复测"。

> **缓解（建议与 C 一起采纳）**：把"不达标"的处置从"立即合并/补题"改为**"列入复核清单，累计样本增大后重判"**；只有当**区间整段低于 0.70** 时才允许直接进入补题/合并流程。这把 C 的噪声风险关在了同一道可辩护的门后面。

**风险 3：不影响任何工具与流程。** 条款结构不变，`analyze.py` 的 `alpha_pass` / `split_pass` 逻辑不变，只需在报告模板里加一行区间与一段声明。

**优点**：改动面最小、不新增需要维护的数字；同时用"区间必写"满足《Standards》(2014) 标准 2.19（"it is unacceptable to say simply, 'The reliability/precision of scores on test X is .90.'"，p.47）与 Kennedy (2022)（"reliability should not be reported as a point estimate, but as an interval"）的要求。

## 5. 我的推荐与理由

> **⚠️ 这是建议，最终由维护者拍板。** 本节不构成决定，票 #29 仍开着。

### 5.1 推荐

**第一轮：选 C，并且强制采用 A 的报告写法**——即：判定仍用 α̂ ≥ 0.70，但**每份报告必须同时给出 95% 区间、n、k 与固定功效声明**；并把"不达标"的处置改为"先列入复核清单，区间整段低于 0.70 才直接补题/合并"。
**B 推迟**：等累计样本达到 **n ≥ 253**（区间半宽 ≤ 0.05，笔记 §1.2）后再一次性定版启用；届时候选为 **T = 0.62**（等效门槛 α̂ ≳ 0.676），并接受"质量主张由 0.70 下调到 0.62"是自觉选择；若不愿下调，则用 **T = 0.70** 并把启用门槛定在 **n ≥ 367**（观测 α̂ = 0.74 时）。

### 5.2 理由

1. **第一轮的病根是样本量，不是判据形式。** §3.4 显示：B 的判据在边界处的通过率（0.447）**比现行的点判定（0.556）更低**——换判据形式解决不了"功效约 0.5"，只会把边界挪个位置、把质量主张换个数。
2. **C 的改动面最小**：不新增需要长期维护的数字（不像 B 的 T）、不改 `analyze.py` 的判定逻辑、不改变票 #26 的验收结构；只加"区间必写 + 固定声明 + 处置改复核"三件事。
3. **C 单独不够，A 单独也不够，但两者不冲突**：A 的写法（区间必写）解决"读者把点估计当结论"；C 解决"第一轮不能完全没有判定"。**A + C 的组合 = C 的判定 + A 的写法**，这是本推荐的实质。
4. **A 单独不够**：放弃护栏后，"抓真差"这一半很弱（真 α = 0.65 的维第一轮只有 16% 被拦下，§4.1）；而 C 保留了护栏（并把它收紧到"区间整段 < 0.70"）。
5. **B 应当延后**：阈值一旦定版就是事实标准，而第一轮的数据量**尚不足以验证任何阈值是否合适**（§3.1/§3.2/§3.4 全部显示门槛随 n 漂移 0.05–0.07）。延后到 n ≥ 253 定版，能一次性把 T、启用 n 档与等效门槛一起锁定。
6. **若维护者更看重"第一轮就要方向性结论"**：那就选 B，但必须同时接受其中一个代价——**要么** T = 0.60（质量主张减半，判别力与现行相当），**要么** T = 0.62/0.65（质量主张更低但第一轮补题量更大）。**没有第三条既保质量主张又保第一轮结论的路。**

## 7. 对票 #26 验收条款第 7 条的拟改写文本（三版 + 一版合并建议）

> 以下每一版都是**可逐字替换**第 7 条的完整条文。措辞已按"维护者可直接粘"写，未留占位符。

### 7.1 A 版（描述式）

> **7. 信度**：每维报告 Cronbach's α 与分半信度（Spearman-Brown 校正）的**点估计与 95% 置信区间**，并注明 **n 与 k（24）**。**第一轮（n ≤ 80）不据 α 或分半的点估计判定达标/不达标**，也不因点估计未过 0.70 而触发合并维度或补题；**只有当某维 α 的 95% 区间整段落在 0.70 之下时**（n = 80 时相当于观测 α̂ ≲ 0.577，n = 60 时 ≲ 0.551），才判定该维内部一致性明显不足，进入「合并维度或补题再复测」流程。该维同时列入**复核清单**，累计样本达到 253 份后重判（此时区间半宽 ≤ 0.05）。补题、删题都要留痕并复跑，不得为了让 α 过线而挑着删题。

### 7.2 B 版（区间判据，阈值 T = 0.62）

> **7. 信度**：每维的判定改用**区间判据：「Cronbach's α 的 95% 置信区间下界 > 0.62」**（k = 24，Feldt 型区间；n = 80 时该判据等效于观测 α̂ ≳ 0.718）。报告必须写出 α 的点估计、95% 区间、n 与 k，并注明该判据的含义是「以 95% 置信度可以说真实 α > 0.62」，**不声称真实 α ≥ 0.70**。分半信度（Spearman-Brown 校正）因本项目尚无区间公式，本轮仍按点估计 ≥ 0.70 记录并报其抽样波动；**α 与分半判定冲突时以 α 为准，该维记为「待复核」，不据此改题**。区间下界 ≤ 0.62 的维进入「合并维度或补题再复测」流程。**本阈值自本条生效起为项目事实标准**：其唯一来源为 `pilot/analyze.py` 的常量，作业包 §七阈值表与本条均引用它；任何修改须在本票留痕（改前 → 改后、依据、生效的 n 档、生效日期）。补题、删题都要留痕并复跑，不得为了让 α 过线而挑着删题。

### 7.3 C 版（维持点判定 + 强制功效声明）

> **7. 信度**：每维 Cronbach's α ≥ 0.70、分半信度（Spearman-Brown 校正）≥ 0.70。**报告必须同时给出每维 α 与分半的点估计、95% 置信区间与 n、k，并必须附上以下固定声明（逐字，不得删改）**：「本条以点估计 α̂ ≥ 0.70 判定。在 n = 60–80 的样本量下，该判据在阈值恰好落在真实 α 上时（真实 α = 0.709）的通过概率约为 0.55（n = 60/80/100 分别为 0.552/0.564/0.577），且不随样本量改善（n = 300 时为 0.578）；真实 α = 0.683（略低于阈值）时仍有 0.386/0.375/0.399 的概率被判为达标。因此本判定只作线索，不构成「该维质量合格」的结论。」**α 与分半判定冲突时以 α 为准，该维记为「待复核」，不据此改题。**不达标的维先列入**复核清单**，累计样本增大后重判；**只有当某维 α 的 95% 区间整段落在 0.70 之下时**（n = 80 时相当于观测 α̂ ≲ 0.577），才直接进入「合并维度或补题再复测」流程。补题、删题都要留痕并复跑，不得为了让 α 过线而挑着删题。

## 8. 方法与限制

### 8.1 本文件做过的计算

1. **复现笔记 §1.2 的解析式**：用笔记给出的 Feldt 型公式（下界 = 1−(1−α̂)·F<sub>1−α/2</sub>(n−1,(n−1)(k−1))，上界 = 1−(1−α̂)·F<sub>α/2</sub>(n−1,(n−1)(k−1))），F 分位函数取 SciPy 1.13.1 的 `scipy.stats.f.ppf`。复现 §1.2 表的 10 档区间，**最大绝对偏差 0.0005**；半宽反解的 5 个 n 目标**全部一致**（§1.4）。
2. **反解门限**（本文件自算）：对 α̂ 单调性用二分法求"使区间下界（或上界）恰为某值"的 α̂；再对 n 逐一扫描求"下界首次超过 T"的最小 n。
3. **正态近似的功效**（本文件自算）：P(α̂ ≥ 阈值) 与 P(判据成立) 用 α̂ ~ N(真实 α, SD) 近似，SD 取笔记 §1.3 的推演值（0.810→0.047、0.792→0.052（插值）、0.772→0.060、0.753→0.060、0.732→0.061、0.709→0.064、0.683→0.070）；真 α = 0.65 / 0.60 两行的 SD（0.075 / 0.083）为**外推**，已在表中标注。**这是近似，不是蒙特卡洛。**
   - 与笔记 §1.3 的蒙特卡洛值对照：真 α = 0.709 → 本文件 0.556 vs 笔记 0.552（n = 60）；真 α = 0.683 → 本文件 0.404 vs 笔记 0.386。**差 0.01–0.02**，说明近似可用于判断量级，不宜当精确值引用。
4. **用 `analyze.py` 的实现复算**：直接 `import analyze` 调用 `cronbach_alpha()` / `split_half()`，在合成样本上复现 `pilot/out/analysis.json` 的 α 与分半（INT 0.7403/0.7092、SNT 0.7138/0.7954、TFS 0.8069/0.8149、JPS 0.8358/0.8133，**完全一致**），并另取 n = 80 子样本演示报告形态（§2.5）。

### 8.3 限制（逐条）

1. **本文件没有真人数据。** 所有示例场景均为**假设值**；唯一出现的实测数字来自**合成样本**，已逐处标注【实测·合成】。
2. **本文件不改动任何既有文件**（`analyze.py`、票面、研究笔记、作业包均未动）。§5.3 列出的四处同步改动是**建议**，尚未执行。
3. **解析式在题目异质时略偏窄**（笔记 §7.3：b ~ N(0, 0.8) 时 n = 60 的 95% 宽度为 0.289，解析式给 0.269）。⇒ 报告里的区间应以实测/自举为准，解析式当**下界**用。
4. **分半信度没有区间公式**（Charter 2000 全文未取得，笔记 §7.4 第 9 条）⇒ 分半的一切区间只能由重抽样给出；本文件模板里分半的区间是**占位符**，不是编的数字。
5. **功效表是正态近似**，不是蒙特卡洛；且真 α = 0.65 / 0.60 两行用了外推的 SD。只用于判断量级与方向。
6. **T 的取值没有任何外部依据**。标准（《Standards》2014 全文）未给任何信度阈值或最小样本量数字（笔记 §7.5）；Bonett (2002) 给的是**样本量规划方法**，不是阈值；Kelley & Cheng (2012) 同理。⇒ **T = 0.60 / 0.62 / 0.65 是政策选择，不是"学界公认"。**
7. **"n ≥ 253"是精度目标（区间半宽 ≤ 0.05）的反解值**，不是任何标准或文献规定的最小样本量（笔记 §7.5 已明确标注"未找到官方依据"）。
8. **本文件只处理 α 与分半这一条**；锚定审计、分歧率、极端题、切点定版的口径问题在笔记 §5 与 §6.2 已有结论，本文件不重复、不改动。

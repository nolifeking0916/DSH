# 样本量与信度推断边界（第一轮真人试测 60–80 份）

> **一句话结论**：第一轮 60–80 份真人样本**只能支持"带区间的描述"，不能支持"达标/不达标"的点判定**——因为验收阈值 α ≥ 0.70 恰好落在被检验量（真实 α）的边界上，此时观测到 α̂ ≥ 0.70 的概率约为 **0.55**（真 α = 0.709 时，n = 60/80/100/200/300 分别为 0.552/0.564/0.577/0.571/0.578），**加样本量也不改善这一点**（阈值不动，边界上的检验功效永远是 50%）；能改善的是**估计精度**：α̂ 的 95% 区间半宽在 k = 24、n = 60–80 时约为 **±0.089 ~ ±0.103**，所以「α = 0.72」与「α = 0.75」在这个样本量下**不可分辨**（差 0.03 只有区间半宽的 0.29–0.34 倍），"α ≥ 0.70 达标"这条线**落在噪声带内**，只能写成"α 点估计 0.7x，95% 区间 [a, b]"；唯一能站住的判定写法是"**整段区间都在 0.70 同一侧**"（n = 60 时需 α̂ ≳ 0.793 或 ≲ 0.587，n = 100 时 ≳ 0.774 或 ≲ 0.614，n = 300 时 ≳ 0.744 或 ≲ 0.652）。另外三条边界：① **分半信度与 α 不能互相替代**——α 与奇偶分半 SB 在同一样本上"一个过一个不过"的判定冲突率，在真实 α 接近阈值时高达 **15%–24%**（n = 60–100），且 SB 的抽样 SD 系统性略大于 α（0.055–0.084 vs 0.047–0.073）；② **五级人数在 n = 60–80 只有 2–3 档有信息量**，且按当前"绝对锚点 + 整体档取四维最低"的计分规则，**整体档的"优秀/顶尖"两档在结构上几乎不可达**（项目自己的合成样本 n = 112 中：整体档 顶尖 0 人、优秀 0 人；四维同时 ≥ 22 分的联合概率约 2.7 × 10⁻⁷，实测 0/112）；③ **"累计 ≥ 100 份再校准"是工程约定，不是标准里的数字**——《Standards》(2014) 只要求"报告信度研究的方法与样本量"（标准 2.19, p.47）、"项目性质估计的样本应足够"（标准 4.10, p.88–89），从未给出任何最小样本量；100 份在方法上能支撑的是"α 区间半宽 ≈ ±0.08"，**不足以把参照分布切点定版**（单维分位切点在 n = 60 时 95% 取值范围横跨 4 分 ≈ 整整一档，n ≈ 300 才收敛到 ±1 分），所以建议把"100 份开候选切点"与"切点定版（建议 ≥ 300，理想 500+）"拆成两道关。

## 1. 问题一：n = 60–80 时，观测到的 α 的抽样误差有多大？

### 1.1 设定与口径

- 每维 **k = 24 题**（二极强制对比，计分 1 = 选了更有效的一端），第一轮 **n = 60–80 人**。
- 信度统计量按本项目口径计算（`analyze.py:328–352`）：α = Cronbach's α；分半 = 奇偶分半 + Spearman-Brown 校正。
- **α̂ 的不确定度有两个来源，必须分开**：① **抽样误差**（这批人换一批人会变多少）——随 n 下降；② **测量误差**（这个人换一个时间答会不会变）——**不随 n 下降**。本节只讲①，②见 §3.4。

**【实测·合成数据】**用项目自己的合成样本 `pilot/out/samples.json`（剔除异常后 n = 112）做 bootstrap，取 n = 60 / 80 的子样本：

| 维 | α（n=112 全样本） | n=60 子样本均值 ± SD（95% 区间） | n=80 子样本均值 ± SD（95% 区间） |
|---|---|---|---|
| INT | 0.7403 | 0.730 ± 0.055 [0.610, 0.818] | 0.728 ± 0.047 [0.625, 0.804] |
| SNT | 0.7138 | 0.705 ± 0.053 [0.572, 0.789] | 0.708 ± 0.043 [0.608, 0.777] |
| TFS | 0.8069 | 0.801 ± 0.036 [0.725, 0.862] | 0.802 ± 0.033 [0.729, 0.855] |
| JPS | 0.8358 | 0.831 ± 0.029 [0.765, 0.878] | 0.831 ± 0.026 [0.776, 0.872] |

### 1.4 回答问题一：三个子问题

**（a）α 观测值的抽样误差有多大？**
n = 60–80 时，单维 α̂ 的 **95% 区间半宽约 ±0.089 ~ ±0.103**（信度越低越宽；真实 α ≈ 0.68–0.71 时更接近 ±0.10）。抽样 SD 约 **0.03–0.07**。一句话：**n = 60–80 只能把每维 α 定位到"±0.1 宽的一个区间"，定位不到 0.01 位。**

**（b）α = 0.72 与 α = 0.75 的差别有没有意义？**
**没有意义。** 差 0.03，在 n = 60 时只有区间半宽的 **0.29 倍**，n = 80 时 **0.34 倍**；在 95% 把握下要把两者分开，需要观测差 ≥ **0.21（n=60）/ 0.18（n=80）**——这个差距本身已经大到没有实用意义。⇒ **报告里写"0.72"还是"0.75"没有区别；任何基于 0.03 量级差异的"改进/退步"结论都不成立。**

**（c）"α ≥ 0.70 达标"这条线可靠吗？**
**不可靠，而且"不可靠"这件事加样本量也治不好。** 原因是结构性的：阈值 0.70 与被检验的真实 α 重合时，这是一个**落在检验边界上的假设检验**，真实 α = 0.709 时观测到 α̂ ≥ 0.70 的概率是 **0.55（n=60）→ 0.58（n=300）**，基本不变；真实 α = 0.683 时也有 **0.39 → 0.36** 的概率被误判为"达标"。⇒ **这条线只筛得掉"明显差"（真实 α ≤ 0.68 时仍有约四成会被误判通过；真实 α ≤ 0.65 时误判率降到 10% 上下），分辨不了"刚好过线"和"差一点不过"。**

**因此，唯一站得住的判定写法是把 α 报成区间，并按"整段区间在阈值同一侧"下结论**（【解析】，k = 24）：

| n | 要说"整段在 0.70 之上"需 | 要说"整段在 0.70 之下"需 |
|---|---|---|
| 60 | α̂ ≳ **0.786** | α̂ ≲ **0.551** |
| 80 | α̂ ≳ **0.777** | α̂ ≲ **0.577** |
| 100 | α̂ ≳ **0.770** | α̂ ≲ **0.593** |
| 200 | α̂ ≳ 0.752 | α̂ ≲ 0.630 |
| 300 | α̂ ≳ 0.744 | α̂ ≲ 0.644 |
| 500 | α̂ ≳ 0.735 | α̂ ≲ 0.658 |
> 表内为三位小数；精确值：之上 0.7864 / 0.7770 / 0.7703 / 0.7524 / 0.7438 / 0.7348，之下 **0.5509 / 0.5767 / 0.5931 / 0.6297 / 0.6443 / 0.6581**（n = 60/80/100/200/300/500）。按精确值代回，区间端点恰好落在 0.70 上；表内三位小数会带来 ±0.0003 的舍入差。

落在两条线之间（n = 60 是 **0.551–0.786**、n = 80 是 **0.577–0.777**，宽约 0.2）→ **结论只能写"不确定"**。
这条与标准一致：标准 2.19 明确"**it is unacceptable to say simply, 'The reliability/precision of scores on test X is .90.'**"（p.47）；Kennedy (2022) 的实证结论也是"**reliability should not be reported as a point estimate, but as an interval**"（F25）。标准 2.3 注释还要求**分维**都要报信度（本项目四维分开报，做法正确），并要给到足以让使用者判断"是否够精确"的信息（F3）。

## 2. 问题二：分半信度（SB 校正）与 α 哪个更稳、能不能互相替代

### 2.1 它们是同一族证据，不是两份独立证据

- **Cronbach (1951) 原文摘要**（F16）：α 是"**the mean of all split-half coefficients resulting from different splittings of a test**"，且"**Tests divisible into distinct subtests should be so divided before using the formula**"。
  ⇒ **α 就是"全体二分切法的平均"**；奇偶分半 SB 只是其中一次切分的样本值。**两者不是互相独立的两个证据源**，而是同一族（内部一致性）里的一个总体量与一个抽样量。
- **标准 2.5**（F4，p.43）：split-halves 的两半必须在"**content and statistical characteristics**"上可比。
  **【实测】本项目满足这一条**：每维 24 题按 `INT-01…INT-24` 顺序排列，锚点 a/b 交错、情境各不相同（见 `items/m1_items.json`），奇偶两半在内容与锚点构成上可比（可用 `analyze.py` 的 `split_half()` 复算）。
- **标准 2.6**（F5，p.44）：不同种类的变异对应的系数**不得互换解读**；内部一致性、替代式、重测三种系数各有各的误差定义。
  ⇒ α 与 SB 同属"内部一致性"，**在"这一族"内可以互相参照**；但**不能当成两份独立证据叠加**（不能因为"α 过了、分半也过了"就当成两次独立验证）。
- **Sijtsma (2009)**（F20）：α 作为信度估计"suffer from major problems"，且"**statistics based on a single test administration do not convey much information about the accuracy of individuals' test performance**"——这句话同时约束 α 与分半：两者都只是内部一致性，都不能说明"这个人答得准不准"。

### 2.2 【推演】谁更稳

同一总体、同一抽样下（推演，参数见 §1.3）：

| 真实 α（四维均值） | n | α 单维抽样 SD | SB 单维抽样 SD | **"一个过一个不过"的判定冲突率** |
|---|---|---|---|---|
| 0.810 | 60 | 0.047 | 0.055 | **0.040** |
| 0.810 | 100 | 0.047 | 0.055 | 0.014 |
| 0.772 | 60 | 0.060 | 0.071 | **0.116** |
| 0.753 | 60 | 0.062 | 0.084 | **0.163** |
| 0.732 | 60 | 0.062 | 0.074 | **0.193** |
| 0.709 | 60 | 0.067 | 0.071 | **0.241** |
| 0.683 | 60 | 0.067 | 0.079 | **0.231** |

**结论**：**α 略稳于奇偶分半 SB**（单维抽样 SD 小约 0.007–0.022；SB 把 24 题砍成两个 12 题再校正，丢掉了半个题集的信息量，波动更大），但两者**数量级相同**。

### 2.3 回答问题二

**能不能互相替代？不能。** 三条理由：

1. **它们不是两份独立证据**（Cronbach 1951：α 是全体二分的平均），同时报两个数**不等于做了两次验证**。因此验收判据"α ≥ 0.70 且分半 ≥ 0.70"应读作**"两个相关指标都必须过关"**，而**不是**"两个独立证据都支持"。
2. **在 α 接近阈值时，两个判定会打架**：冲突率 **15%–24%**（真实 α ≈ 0.68–0.73，n = 60）。换句话说，**每 4–6 份样本里就会有 1 份出现"α 过了、分半没过"（或反过来）**。这条冲突本身就是"这批题库就在阈值附近"的信号，不该被当成某个数算错了。
3. **口径纪律提醒（本轮实际踩到并已修正）**：本项目题库的 `anchor` 在 a/b 之间交错，**算 α / 分半必须先按锚点对齐**（1 = 选了更有效的一端），否则不同锚向的题会互相抵消。`analyze.py:340` 做的就是这件事（**已确认正确**）。作为对照，本轮第一版推演若直接用原始 a/b 编码（0=选 a 侧 / 1=选 b 侧）计算，得到的 α **全部为负（约 −0.19 ~ −0.01）**，且分半 SB 的抽样 SD 达到 **1.4–1.6**（r 趋近 −1 时的退化表现）——**口径错了不会报错，只会给出看起来像数的垃圾**。

**给试测报告的写法建议**：两个数都报点值 + 各自 95% 区间 + n/k；判定行写"**α 与分半均 ≥ 0.70 / 其中一项未过（需在 n 增大后复核）**"，不要写"两项独立验证通过"。

## 3. 问题三：五级分档在 n = 60–80 时的人数波动有多大

### 3.1 【解析】每档人数的抽样波动

分档人数服从多项分布，**每档人数的标准差 = √(n·p(1−p))**（p 为该档在总体中的占比）：

| n | p=0.02 | p=0.05 | p=0.10 | p=0.20 | p=0.30 | p=0.40 |
|---|---|---|---|---|---|---|
| 60 | 1.08 | 1.69 | 2.32 | 3.10 | 3.55 | 3.79 |
| 80 | 1.25 | 1.95 | 2.68 | 3.58 | 4.10 | 4.38 |
| 100 | 1.40 | 2.18 | 3.00 | 4.00 | 4.58 | 4.90 |
| 200 | 1.98 | 3.08 | 4.24 | 5.66 | 6.48 | 6.93 |
| 300 | 2.42 | 3.77 | 5.20 | 6.93 | 7.94 | 8.49 |
| 500 | 3.13 | 4.87 | 6.71 | 8.94 | 10.25 | 10.95 |

**读法**：n = 60 时，一个占比 10% 的档，人数的标准差是 **±2.3 人**、95% 区间约 **±4.6 人**；占比 2% 的档，95% 区间约 **0–4 人**。

### 3.2 【实测·合成数据】整体档（= 四维取最低）在 n = 60–80 时的结构问题

**这一条比抽样波动更要紧，是计分规则本身的问题。** 用项目自己的合成样本（`pilot/out/samples.json`，剔除异常后 n = 112）：

| 维 | 顶尖 | 优秀 | 良好 | 合格 | 待提升 |
|---|---|---|---|---|---|
| INT | 7 (6.3%) | 24 (21.4%) | 45 (40.2%) | 27 (24.1%) | 9 (8.0%) |
| SNT | 1 (0.9%) | 19 (17.0%) | 41 (36.6%) | 37 (33.0%) | 14 (12.5%) |
| TFS | 3 (2.7%) | 14 (12.5%) | 30 (26.8%) | 42 (37.5%) | 23 (20.5%) |
| JPS | 2 (1.8%) | 19 (17.0%) | 26 (23.2%) | 37 (33.0%) | 28 (25.0%) |
| **整体档（四维最低）** | **0 (0%)** | **0 (0%)** | 11 (9.8%) | 43 (38.4%) | 58 (51.8%) |

- 各维进入"顶尖"（≥22 分）的比例：INT 6.3%、SNT 0.9%、TFS 2.7%、JPS 1.8%；**独立近似下"四维同时 ≥ 22"的联合概率 ≈ 2.7 × 10⁻⁷**；**实测：四维同时 ≥ 22 的人数 = 0 / 112**。
- 【推演】在项目生成模型下重抽样，整体档"顶尖"为空的概率 = **1.000**（n = 60/80/100/200/300 各档均如此）。

⇒ **在当前"绝对锚点（每维顶尖 = 22–24）+ 整体档取四维最低"的规则下，整体档的"顶尖"与"优秀"两档实际上不可达。** 这不是抽样波动，是**规则结构 + 分数分布形状**的乘积。这意味着验收判据里"报告里必须同时给分数分布和五级人数"这条，在**整体档层面**只能给出 3 档（待提升/合格/良好），给不出 5 档。

> ⚠️ **口径提醒**：上面的占比来自**合成数据**（生成模型的性质），不是真人 HR 群体的分布。真人分布若更平（各维顶尖比例更高），联合概率会上升。但"四维同时达到 22 分"这个**算术门槛本身**不会变——**端点档的可达性必须用真人数据重新核算，并且可能需要改计分规则（例如整体档改用加权/最短板维度的连续刻度，而不是"四维取最低档"）**。这是一个**待用真人数据验证的设计缺口**，不是本轮能定论的事。

### 3.3 【解析 + 推演】"每档人数稳定"到可接受水平需要多大 n

**目标 A：每档期望人数 ≥ 8**

| 该档在总体的占比 p | E ≥ 8 需 n | 相对波动 CV ≤ 0.30 需 n | **95% 把握至少 8 人需 n** |
|---|---|---|---|
| 0.02（顶尖档量级） | 400 | 545 | **655** |
| 0.05 | 160 | 212 | 260 |
| 0.10 | 80 | 101 | 129 |
| 0.15 | 54 | 63 | 85 |
| 0.20 | 40 | 45 | 63 |
| 0.25 | 32 | 34 | 50 |

⇒ **"每档 ≥ 8 人"不是由 n 单独决定的，是由该档在总体中的占比决定的。** 在当前分布形状下（顶端档占比 1%–3%），n = 60–80 **远远不够**（n = 60 时顶尖档期望人数就是 0.6–1.8 人，95% 区间 0–4）；要到 95% 把握，端点档需要 n ≈ 260–655。

**目标 B：分位切点稳定（校准口径）**

【推演】用项目合成样本的经验分布重抽样，算**单维（0–24 分）** P90/P70/P45/P25 切点（口径与 `analyze.py:percentile_cutpoints()` 一致，`analyze.py:443` 对**每维分**算切点）：

| n | 顶尖(P90) SD（95% 取值范围） | 优秀(P70) SD（范围） | 良好(P45) SD（范围） | 合格(P25) SD（范围） |
|---|---|---|---|---|
| 60 | 0.75（**18–22**） | 0.81（**16–20**） | 0.57（13–17） | 0.75（11–15） |
| 100 | 0.57（19–22） | 0.59（16–19） | 0.45（14–16） | 0.56（10–15） |
| 300 | 0.21（20–22） | 0.39（16–19） | 0.23（14–16） | 0.33（12–14） |
| 1000 | 0.04（20–21） | 0.21（17–18） | 0.04（15–16） | 0.17（12–13） |

**档宽对照（0–24 尺度）**：顶尖 3 分、优秀 4 分、良好 4 分、合格 5 分、待提升 9 分。
⇒ **n = 60–80 时，顶尖切点的 95% 取值范围横跨 4 分（18–22）——整整一个"优秀+顶尖"的距离**；切点动 1 分就是动 1/3 到 1/4 个档。**"分位切点变动小于半档"这个目标在 n = 60–80 达不到；n ≈ 300 才收敛到 ±1 分（≈1/4 档），n ≈ 1000 才稳定到 0–1 分。**

### 3.4 【推演】与 n 无关的那一半：分类的测量误差

标准 2.16（F8，p.46）要求：做分类决策时，报告"**两次施测分类一致的比例**"。这个量**不随 n 改善**——它是信度与分数分布形状的函数。

【推演】在项目生成模型下（flip = 0.00 与 0.04 两档），按 SEM = SD·√(1−α) 施加两次独立测量误差，计算同一真分被判到同一档的概率：

| 维 | α | SD | SEM | 各切点处的分类一致率 | 四切点均值 |
|---|---|---|---|---|---|
| INT | 0.785 | 4.53 | 2.10 | 0.915 / 0.833 / 0.824 / 0.910 | **0.870** |
| SNT | 0.800 | 4.79 | 2.14 | 0.895 / 0.825 / 0.846 / 0.932 | 0.874 |
| TFS | 0.818 | 4.95 | 2.11 | 0.860 / 0.842 / 0.888 / 0.958 | 0.887 |
| JPS | 0.838 | 5.21 | 2.10 | 0.862 / 0.852 / 0.893 / 0.956 | 0.891 |

⇒ **五级分类的重测一致性只有约 87%–89%，且中间两个切点（良好/优秀边界）最不稳（82%–85%）。** 这条**加多少样本都不会变**。

**这一条是本节最重要的区分**：

| | 随 n 下降？ | 第一轮 60–80 能改善吗 |
|---|---|---|
| "每档人数是多少"的**抽样**误差 | 是（∝ 1/√n） | 有限（顶端档几乎无改善） |
| "分位切点定在哪"的**抽样**误差 | 是（∝ 1/√n，但受整数分粗糙性限制） | 有限（顶尖切点仍可跨 4 分） |
| "一个人被判到哪一档"的**测量**误差 | **否** | **不能** |

⇒ 报告口径必须把这两层分开写，否则读者会把"人数占比估计得不准"误读成"档位定得不准"，或反之。

## 4. 问题四：「累计 ≥ 100 份再校准」这个门槛意味着什么

### 4.1 在 n = 96 题、四维分档的设定下，100 份换来了什么

【解析 + 推演】汇总：

| 目标 | n = 60–80 | n = 100 | 要达到"可定版"需要 |
|---|---|---|---|
| 每维 α 的 95% 区间半宽 | ±0.089–0.103 | **±0.080** | ±0.05 → **n ≥ 253**；±0.04 → n ≥ 394 |
| "整段在 0.70 之上"需 α̂ ≳ | 0.777–0.786 | 0.770 | 0.744（n = 300） |
| 单维 P90 切点 95% 取值范围 | 18–22（跨 4 分） | 19–22（跨 3 分） | 20–22（n = 300）/ 20–21（n = 1000） |
| 端点档（p ≈ 2%）人数 95% 区间 | 0–4 | 0–4 | 95% 把握 ≥ 8 人需 **n ≈ 655** |
| 分类重测一致性 | ≈ 87%–89% | 同左 | **不随 n 变**（受 α 与 SD 限制） |

⇒ **n = 100 的实际增益是：α 的区间从 ±0.10 收到 ±0.08；切点从"跨 4 分"收到"跨 3 分"。它**没有**把任何一项推到"可以定版"的水平。**

### 4.2 "100"在方法学上有没有依据？

**明确结论：没有官方依据——它是一个工程约定。**

- **《Standards for Educational and Psychological Testing》(2014) 里没有任何最小样本量数字。** 相关条款只做"程序性"要求：
  - 标准 2.19（F9，p.47）：信度研究要报告"**method of data collection, sample sizes**, means, standard deviations…"；
  - 标准 4.10（F11，p.88–89）：估计项目性质所用"**sample should be described and should be of adequate size and diversity**"；
  - 标准 3 章 p.66（F10）：样本量小时"**data may sometimes be accumulated over operational administrations**"；
  - 标准 11 章 p.171（F14）："**Sample size affects the degree to which different lines of evidence can be used**"。
  → 标准提供的是**"必须报告样本量"与"样本量决定能用哪种证据"**的框架，**不提供阈值**。**"100"这个数在标准里找不到依据。**
- **文献侧**：
  - Kennedy (2022)（F25，**本轮通读全文**）：实证比较 n = 20…400，结论"**at least one hundred (100) subjects should be used**"，并强调"**reliability should not be reported as a point estimate, but as an interval**"。该文同时**转述**（本轮未读到原文）Charter (1999) 主张"最小 400"、Charter (2003) 指 α 在小样本下不稳、Kline (1986) 与 Nunnally & Bernstein (1994) 主张"最小 300"。⇒ **这些数字来自转述，不是本轮直接读到的一手依据。**
  - **Bonett (2002)**（F17）："**The sample size formulas can be used to determine the sample size needed to test coefficient alpha with desired power or to estimate coefficient alpha with desired precision.**" ⇒ **这才是"该用多大 n"的方法学工具**（按精度反解），而不是拍一个整数。本笔记 §1.2 的反解表就是这个思路。
  - **Bonett & Wright (2014)**（F18）：同一方向的完整版（区间 + 检验 + 样本量规划）。
- **⚠️ 关于用户清单里的"Kelley 2008"**：经 Crossref 与作者本人著作目录核实，**Kelley (2008) 是《Sample Size Planning for the Squared Multiple Correlation Coefficient》（R² 的样本量规划，MBR 43(4):524–555），对象不是信度系数**。信度版本的对应文献是 **Kelley & Cheng (2012)**（F24，*Methodology* 8(2):39–50，"Estimation of and Confidence Interval Formation for Reliability Coefficients of Homogeneous Measurement Instruments"）。⇒ **如果要把"Kelley 的窄区间样本量规划"用到本项目，引用对象应当换成 Kelley & Cheng (2012)，不能引 Kelley (2008)。**

### 4.3 给门槛的可执行改法（不改动阈值本身，只加分层）

**建议把现在的一刀切拆成三道关，并写进 `m1_design.md` 第八节与《真人试测作业包》**：

| 关 | 触发条件 | 能做什么 | 不能做什么 |
|---|---|---|---|
| 关 1：**候选切点** | 累计 ≥ 100 份有效作答 | 按 `percentile_cutpoints()` 出**候选**参照分布切点（P90/P70/P45/P25），与绝对锚点并列展示差异 | 不得写进裁定表、不得对外当阈值 |
| 关 2：**切点定版** | 累计 **≥ 300 份**（理想 500+），且**每维分位切点的 95% 取值范围 ≤ ±1 分** | 把参照分布切点写进裁定表（留痕） | —— |
| 关 3：**档位人数对外可报** | 各档在总体的占比 ≥ 10% 时 n ≥ 129；≥ 5% 时 n ≥ 260；≥ 2% 时 n ≥ 655 | 把"五级人数"作为对外结论 | —— |

**并且（与 §3.4 一致）**：无论 n 多大，**都要报"两次施测分类一致的比例"**（标准 2.16），因为它不随 n 改善。

**另有一条与门槛无关但必须并行的口径**（沿用项目既有硬约束）：**合成数据上的 α 是生成模型的性质，不是题目的性质**，不能当信效度证据（`pilot/试测报告_模拟版_20261024.md` §三；本笔记 §1.3 的推演数字同理）。阈值与题库改动只在真人证据支持下做，并逐题留痕（`m1_design.md` 第八节："校准前不得按单个候选人的表现调阈值"）。

## 5. 问题五：两条内容质量判据的抽样误差

### 5.1 「某题 ≥ 90% 人选同一端 → 该题重写」

【解析】二项模型，判据为"观测同端率 ≥ 0.90"。

**触发概率（真实同端率为 p 时）**：

| n | p=0.50 | p=0.70 | p=0.80 | p=0.85 | p=0.90 | p=0.92 | p=0.95 |
|---|---|---|---|---|---|---|---|
| 60 | 0.000000 | 0.0002 | 0.031 | 0.185 | 0.607 | 0.798 | 0.970 |
| 80 | 0.000000 | 0.00000 | 0.013 | 0.134 | 0.593 | 0.811 | 0.982 |
| 100 | 0.000000 | 0.00000 | 0.006 | 0.099 | 0.583 | 0.824 | 0.989 |
| 200 | 0.000000 | 0.00000 | 0.0001 | 0.026 | 0.559 | —— | —— |

**观测到 90% 时，真实同端率的 95% 区间（Wilson）**：n = 60 → **[0.799, 0.953]**；n = 80 → **[0.815, 0.948]**；n = 100 → [0.826, 0.945]。

**读出来的三条事实**：

1. **误报风险几乎为零**：真 p = 0.50 的题在 n = 60–200 下被触发的概率 < 10⁻⁵；96 题全平衡时，**期望误报题数 ≈ 0**（≤ 96 × 10⁻⁵）。⇒ 这条判据**不会冤枉真正平衡的题**。
2. **漏报风险很高**：n = 60 时，真 p = 0.90 的题只有 **61%** 会被触发，真 p = 0.85 的题只有 **18%**；真 p = 0.80 的题只有 3%。n = 80 略好（59% / 13% / 1.3%）。
3. **这条判据的灵敏度随 n 增大而下降**（在 p < 0.9 一侧尤其明显：真 p = 0.80 的触发率从 n = 60 的 3.1% 降到 n = 200 的 0.01%），因为样本越大、样本同端率越贴住真值。而当真 p **恰好等于 0.9** 时，触发概率**恒在 50% 上下，与 n 无关**（阈值与真值重合时的必然结果，与 §1.4 的 α ≥ 0.70 同一结构）。
   ⇒ **推论：这条判据在不同样本量下的"触发题数"不可横向比较**；跨轮次比较"触发了几道题"是无效的。

**因此第一轮的正确用法**：

- 把触发结果当**筛查信号**，不当结论：写"**触发题号 + 每题同端率 + Wilson 95% 区间**"，**不要**直接写"该题判据太露骨 → 重写"。
- 一道被触发的题，真实同端率可能低到 **0.80（n = 60）**——也就是**五个人里就有一个真的不同意**。这类题要不要改，改的是"题面措辞"还是"判据句"，要靠标注反馈，不是靠这一条比例。
- 若要把它写成有检验的判定，建议改为"**该题同端率的 Wilson 下界 > 0.85**"这类带推断的形式，并在报告里写明用的是哪个形式。

### 5.2 「锚定审计命中率 ≥ 80%」（每维抽 6 题，合计 24 题）

**这是本轮最脆弱的一条判据。** 【解析】二项模型：

- 6 题里"≥ 80%"**只能取到 5/6 = 83.3%**（下一档 6/6 = 100%）。**刚好达标时的 Wilson 95% 区间 = [0.436, 0.970]，宽度 0.533。**
  ⇒ **一句话：真命中率在 0.44 与 0.97 之间都算"刚好达标"。这条判据在 6 题上几乎没有分辨力。**

- **真实命中率 → 通过概率**：

| 每维抽题数 | 需命中 | 真 0.70 | 真 0.80 | 真 0.85 | 真 0.90 | 真 0.95 | 刚好达标的 Wilson 95% CI 宽度 |
|---|---|---|---|---|---|---|---|
| **6（现行）** | 5/6 | 0.420 | 0.655 | 0.777 | 0.886 | 0.967 | **0.533** |
| 12 | 10/12 | 0.253 | 0.558 | 0.736 | 0.889 | 0.980 | 0.401 |
| 24 | 20/24 | 0.111 | 0.460 | 0.713 | 0.915 | 0.994 | 0.292 |
| 48 | 39/48 | 0.057 | 0.500 | 0.826 | 0.981 | 1.000 | 0.217 |
| 96（抽满全部题） | 77/96 | 0.017 | 0.541 | 0.923 | 0.999 | 1.000 | 0.158 |

- **四维联合**：抽 6 题/维时，单维通过率 0.655（真 0.80）→ **四维全通过只有 0.184**；真 0.85 时单维 0.777 → 四维全通过 0.364；真 0.90 时 → 0.615。⇒ **"四维全部 ≥ 80%"在 6 题/维的设定下几乎不可能通过**（即使真实命中率高达 0.90，四维全过也只有 62%）。

- **误差来源的次序**：**题目抽样数是主误差源，标注员人数是次要的**（6 题 CI 宽 0.533；12 题 0.401；24 题 0.292；48 题 0.217；96 题 0.158）。**加标注员不能替代加题目。**

- **【实测】抽样是有偏的（最坏情形）**：按《真人试测作业包》§五，这 6 题/维是按"**判据句与题面措辞的字面锚合度从低到高**"挑出来的**最难锚合的题**（`analyze.py` 的 `audit_priority_real`，24 题清单见作业包 §五；本轮核对：`pilot/out/analysis.json → audit_priority_real` 每维确为 6 题）。
  ⇒ **这 6 题的命中率是"最难情形"的有偏估计，不能当作全题库锚定质量的代表。**
  ⇒ 由此得到两条**方向相反但都成立**的读法：
  - **"审计通过"** 只能读作"**最难的那些题也没崩**"，**不能**读作"该维整体锚定 ≥ 80%"；
  - **"审计不通过"** 是**有信息量的**——它说明最难锚合的题里有 ≥ 2 题换位后选不出同一行为，该维确实需要重标/重写。

- **标准侧依据**：标准 2.16（F8，p.46）要求分类决策要报"两次施测分类一致的比例"；标准 2.6（F5，p.44）要求系数不得跨误差定义互换解读。两者都指向同一件事：**报告里的每个比例都要配区间与误差定义**。

**第一轮的建议写法**：

1. **报原始命中数（x/6）而不是比例**，并附 Wilson 95% 区间；
2. 把判定拆成两句话：**"最难锚合的 6 题中有 x 题换位后仍能选中同一行为"**（事实）＋**"该维锚定质量未达 80% 阈值 → 需重标"**（动作，仅在 x ≤ 4 时触发）；
3. **不要**写"该维锚定命中率 83.3%，达标"——那等于把 [0.44, 0.97] 的区间说成一个精确的点；
4. 若要保留比例阈值，**把每维抽题数提到 12–24**，并把阈值改写成"**x/n 的 Wilson 下界 ≥ 0.80**"这类带推断的写法。

### 5.3 顺带：双人标注分歧率 ≤ 15%（24 题中 ≤ 3 题）

【解析】24 题上的二项：

| 观测分歧 | 分歧率 | Wilson 95% 区间 |
|---|---|---|
| 1/24 | 0.042 | [0.007, 0.202] |
| 2/24 | 0.083 | [0.023, 0.258] |
| **3/24（现行达标线）** | **0.125** | **[0.043, 0.310]** |
| 4/24（超线） | 0.167 | [0.067, 0.359] |

真实分歧率 p → "观测 ≤ 3 题（判达标）"的概率：p = 0.05 → 0.970；p = 0.10 → 0.786；**p = 0.15 → 0.505**；p = 0.20 → 0.264。

⇒ 同 §5.1 的结构：**阈值 15% 恰在边界上时，判"达标"的概率约 50%**。且 24 题的分辨率只能到 4.2% 一档（1 题）。**报告口径：写"本批 24 题中分歧 3 题（分歧率 12.5%，95% 区间 4.3%–31.0%）"，并逐题列出分歧题号**——分歧题清单本身就是这一轮最有行动价值的产出。

### 5.4 顺带：与第三项推理分 |r| < 0.60

【解析】Fisher z 区间，n = 60–300：

| n | 真 r = 0.30 时 95% 区间 | 真 r = 0.50 时 95% 区间 |
|---|---|---|
| 60 | [0.050, 0.515] | [0.282, 0.669] |
| 80 | [0.086, 0.488] | [0.315, 0.648] |
| 100 | [0.110, 0.469] | [0.337, 0.634] |
| 200 | [0.168, 0.421] | [0.388, 0.597] |
| 300 | [0.193, 0.400] | [0.410, 0.580] |

⇒ n = 60–80 时 r 的区间半宽 **0.17–0.23**，**"是否重叠"的判定与"是否 ≥ 0.60"的判定同样有很宽的噪声带**；真 r = 0.5 时区间上界到 0.63–0.67，**会跨过 0.60 这条线**。⇒ 第一轮只能写"**|r| 的 95% 区间为 [a, b]**"，不能写"两套测的是不同东西"。

### 7.3 校验结果（说明推演可信）

- **Feldt 区间 vs 蒙特卡洛**（同模型）：n=60 → MC 95% 宽 0.2391 / 解析 0.2432；n=80 → 0.2105 / 0.2102；n=100 → 0.0687 / 0.0727（高 α 模型）；n=500 → 0.0305 / 0.0324；n=1000 → 0.0213 / 0.0229；n=2000 → 0.0146 / 0.0162。**两者一致到 5%–10% 以内。**
- **题目难度离散会把 α̂ 的方差放大**：b~N(0,0.8) 时 n=60 的 MC 95% 宽度 0.2886，解析式给 0.2689（同质 b=0 时为 0.2425 / 0.2432）。⇒ 解析式在**题目异质**时略偏窄，**报区间时应以实测/自举为准，或把解析式当作下界**。
- **计分口径校验**：原始 a/b 编码下 α 全部为负（约 −0.19 ~ −0.01）、分半 SB 抽样 SD 达 1.4–1.6；按锚点对齐后为正且与 `analysis.json` 同量级。**口径错误不会报错，只会给出垃圾数。**

### 7.4 限制（逐条）

1. **本文件没有任何真人数据。** 第一轮之前，本项目**没有**任何真人作答样本。文中所有信度数字要么来自**合成数据**（生成模型的性质），要么来自**解析式**，要么来自**模拟推演**。**三者都不能当作信效度证据。**
2. **推演的前提是本项目自己的生成模型**（3 画像混合 + 2PL + 真实题面导出的社会赞许拉力）。**真人的分数分布、标注行为、题目理解方式都可能与它不同**，因此推演给出的应是"**在这个模型下会怎样**"，用来判断"要不要现在下结论"，**不是**对真人数据的预测。
3. **本轮推演用 θ ~ N(画像 θ, 0.85) 的个体连续真值**；项目原始生成器没有个体噪声这一层（θ 取画像固定值），这是本轮为贴近真人连续分布所加的**建模选择**，已在推演参数中标明。
4. **α 的区间宽度对题目异质性敏感**（§7.3 第 2 条）：真实题库的难度离散度未知，真人数据下的区间可能比解析式更宽。
5. **分档人数的波动取决于各档在总体的占比**，而占比本身要先有真人数据才知道。本文件给的是"占比 → 所需 n"的对照表，不是"我们只需 n = X"。
6. **整体档"优秀/顶尖"不可达**（§3.2）这一发现基于**合成数据 + 规则算术**；真人分布若更平，可达性会变化，但**规则门槛（四维各 ≥ 22 分）不会变**。⇒ **必须用真人数据复核，并且可能需要改整体档的计分规则**——这是本文件发现的最需要决策的一项，**不在本轮能定论的范围**。
7. **分类决策一致性（约 87%–89%）**是在推演的分数分布与 SEM 下算出的，真人数据下会不同；但它的**性质**（不随 n 改善）是普遍的。
8. **本轮未取得全文的一手文献**（Bonett 2014、Bonett 2002、Charter 2000、Cronbach & Shavelson 2004、Cronbach 1951、Sijtsma 2009、Agresti & Coull 1998、Kelley & Cheng 2012）：正文只引用其**摘要中明确写出的主张**；需要引用其公式或表格时，**必须先取得全文**。
9. **Charter (2000) 的分半信度置信区间公式**（F19）本轮未读到正文，故 §2 的分半区间**未用该公式**，而是**直接用重抽样**给出 SB 的抽样 SD 与判定冲突率——结论不依赖未能核实的公式。
10. 本文件**未修改仓库任何既有文件**，只新增本文件；所有推演脚本与中间产物留在 `/tmp`，**未写入仓库**。

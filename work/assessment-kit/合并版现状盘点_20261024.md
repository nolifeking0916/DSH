# 合并版现状盘点与已知缺陷

> 来源：`云上文旅集团核心人才系列测试_20261024.html`（现版成品）与第一/二/三项三份既有产物，2026-10-24 逐行核对得出。
> 地图只做索引，细节在这里；各票直接取用下面的事实，不必重复盘点。

### 已知缺陷（2026-10-24 自查确认，与两份在用产物同时相关）

- **第二项 1 分项编码溢出**：编码把选项序号按 1-based（1..4）写进 2 位域、解码用 `%4`，序号 4（D）溢出为 0 → **48 道计分题中 10 题的 1 分项集合失真**（Q01/Q04/Q06/Q10/Q21/Q23/Q28/Q37/Q41/Q45）；Q01 这类题会把 1 分发给错误选项。合并版与第二项独立版共用同一段解码代码，**两份产物同时在错**。已开子票跟踪，并作为共享设计源票的前置阻塞。
- **脱敏规则三处不一致**：合并版与第一/第三项是「前 4 + 10 星 + 后 4」，第二项独立版是「前 6 + 8 星」，且第二项自己的文案写「中间 10 位」——按 ADR-0004 统一为只显示后 4 位。
- **结果 JSON 写入未脱敏身份证**：合并版导出字段 `idNo` 是完整身份证号，而首页只承诺「报告中身份证号默认脱敏」。
- **合规页脚与知情同意在合并时整块丢失**：第二项独立版有两行合规页脚与 8 条知情同意条目，合并版没有。
- **「继续上次答题」入口丢失**：第一项与第三项独立版都有，合并版只剩姓名/身份证回填。

### 合并版现状盘点（2026-10-24 逐行核对，供各票直接取用）

- **零 CSS 变量**：颜色字面量 72 处 / 20 个不同值，大小写混用；字号 9 档、圆角 7 档、padding 12 种、margin 12 种、gap 4 种，均无刻度；`font-family` 只 1 处。
- `@media print` 有但**无 `@page`**、**无响应式断点**；零外部资源（link / script / @import / url() / @font-face / img 全无）。
- 六个页面阶段：`#v-start` / `#v-quiz` / `#v-res1` / `#v-res2` / `#v-res3` / `#v-total`，切换靠 `switchTo()` + `show/hide()`。
- 三模块**共用 1 套**按钮条 / 进度条 / 题号面板，题型差异只在 `renderQ()` 内分 4 支 —— 现成的共享管线骨架。
- 题库均为 JS 常量字面量：`M1Q`(96) / `M1TYPES`(16) / `M1_DIMS` / `M1_AXIS_TIP` / `EQ`(8 维 + 16 自评 + 60 情境) / `LG`(40 题 + 8 维 + 5 档)；评分 `scoreM1` / `scoreM2` / `scoreM3`，结果渲染 `renderRes1/2/3` + `renderTotal`。
- 状态只有 1 个 localStorage 键 `core_talent_v1`（三模块答案同键），无分模块键、无独立结果存档；第一/二/三项的四个旧键需在首次加载时清除。
- 合并时删掉的素材：第一项 144 条文案、第三项 56 条文案 + `REPORT` 对象（`must_say` 8 条 / `must_not_say` 6 条）+ 雷达图 + 错题回顾、第二项知情同意与页脚 —— 原件都在独立版里，可直接取回。
- **色板里有两个对比度坑（原型自检揪出）**：仓内 EQ 汇总台的金色 `#C9A55C` 在浅底上只有 2.2:1（只能做装饰或大字，不能做小字）；其 `--muted #77867D` 在浅底上只有 3.6:1（低于正文 4.5:1）——成品统一改用 `#6E5B36` 与 `#5C6A60`。

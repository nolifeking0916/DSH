### 两个必须记住的坑

1. **金色 `#C9A55C` 在浅底上只有 2.21:1** —— 连大字的 3:1 都不到。**只许**做装饰线（分隔线、竖条、进度条填充）、**深绿底上的字与图形**（4.55:1）；浅底上的任何文字一律用 `--sand #6E5B36`（6.43:1）。
2. **`--muted` 不得用 `#77867D`**（只有 3.6:1，达不到正文 4.5:1），固定 `#5C6A60`（纸面 4.66:1）。

### 五级色标（颜色 + 文字双编码）

| 等级 | 胶囊底 / 字 | `data-level` |
|---|---|---|
| 顶尖 | `--lv-t-bg #1E4634` / `--lv-t-fg #F5F0E4` | `T` |
| 优秀 | `--lv-a-bg #E5F1EB` / `--lv-a-fg #1B7A56` | `A` |
| 良好 | `--lv-b-bg #EFF1EF` / `--lv-b-fg #2A5C42` | `B` |

| 待提升 | `--lv-d-bg #FBEDEA` / `--lv-d-fg #8E2F26` | `D` |

胶囊必须写进等级名（`<span class="grade-pill" data-level="A">优秀</span>`），颜色只是辅助——黑白打印与色觉差异下名字仍在。顶尖档在打印态改白底深字 + 深色描边。

**胶囊硬规则（票 #27 定的，机器判定）**：**横向内边距必须 ≥ 圆角半径**（`border-radius:999px` 时半径 = 高的一半）。否则 2 个汉字会落进圆弧区，视觉上「卡边」——`.grade-pill` 原来 `min-height:26px`（半径 13）配 `padding:0 10px`，10 < 13，两个字几乎顶满胶囊。现在 15px。`.tag`（24px → 半径 12）取 13px；`.rep-nav button`（40px → 半径 20）取 22px。**门禁：`src/verify_product.py` 第 9 节会读 CSS 比对，改胶囊必须先过它。**

## 三、字号、间距、形状、触控

- 字号阶：`--fs-1` 12px / `-2` 13px / `-3` 14px / `-4` 15px / `-5` 16px / `-6` 19px / `-7` 22px。**不写字号字面量。**
- 间距阶：`--sp-1` 4 → `--sp-6` 32px。圆角：`--r-s` 8 / `--r-m` 12 / `--r-l` 18。
- 正文与次级文字 ≥ 4.5:1，图形与控件边界 ≥ 3:1（大字号 ≥ 3:1）。
- **触控目标 ≥ 44×44 CSS px**（`--tap`）：按钮、输入框、勾选框、量表格、题号格全部满足；选项卡 64px、量表格 56px。
- 焦点环 3px（浅底 `--focus`，深底 `--focus-dark`），不得被 sticky 顶栏完全遮挡；答题内容区 `scroll-padding-top: 76px`。
- 字体：正文 `--font`（系统无衬线），标题 `--serif`（宋体族）；**不引外部字体**（零外链）。

### 限时机制（票 #25 裁定）

| 项 | 口径 |
|---|---|
| 限时是什么 | **页面功能**：勾选后倒计时跑起来，到点自动交卷（不再靠施测人现场控时） |
| 时长 | 三项合计 **一个 90 分钟钟**（对应每模块建议用时 12 + 30 + 45 ≈ 87 分钟），不是每项各一个钟 |
| 起算点 | 候选人点「同意并开始测试」那一刻（不是在打开页面时） |
| 续答 | 截止时刻存本机（`S.deadline`），**关掉页面再回来按存的时刻继续走** —— 续答不重新给 90 分钟，否则续答就是绕过限时的后门 |
| 到点行为 | 自动交卷 → 落到完成页；未作答的题**按未作答处理**（不计入得分） |
| 截断标记 | 结果 JSON 带 `limitCut`（未答总数 + 分模块未答数），**只在真被截断时出现**；施测人报告顶部与顶栏徽标同时显示「限时到点自动交卷」 |
| 不落什么 | **结果 JSON 不含任何用时字段**（维护者裁定：不把用时落进产品）。本机状态里的 `S.deadline` 只用于断点续答继续计时，不随结果回传 |
| 告知义务 | 勾了限时，告知卡下方多一段「限时与交卷说明」：起算点、90 分钟、到点自动交卷、未作答怎么处理、续答继续计时、结果带截断标记 |
| 门禁 | `src/verify_limit.py`：承诺 ↔ 实现一致（静态）、到点真的会自动交卷（headless 实跑）、结果 JSON 字段白名单 |

> **一句话纪律**：页面上凡是写给候选人看的行为承诺，实现里必须有对应代码；没有实现就先改文案，别先写承诺（这正是本票的由来）。

## 六、打印

**A4 实测结论（2026-10-24，Chrome 155 headless → PDF；票 #27 整改后 6 页）**

- `@page { size: A4; margin: 12mm 12mm 16mm }` —— 集团用纸为 A4；如需 Letter 只改 `size` 一行。
- **页码**：页码用 `@page { @bottom-right { content: counter(page) } }`，**只有 Chrome ≥131 / Edge 支持**；Firefox / Safari 忽略该声明 → 自动降级为**区块编号**（每个报告区块在抬头写「报告区块 N / 4」）。这是浏览器能力边界，不是实现缺陷；**不要**为了跨浏览器页码去做 JS 分页计算。
- **不要用 `position: fixed` 做打印页脚**：固定元素在打印时每页重复，但 `bottom` 负值会跑到页顶、`bottom: 0` 会压住正文最后一行。改用**区块落款**：每块开头有抬头（区块号 + 姓名 + 编号 + 末 4 位），块尾有落款行。
- **`break-inside: avoid` 只对小组件用**（`.compose` `.short-board` `.metric-row` `.bar` `.must li` `.wrong-list li` `.keep`）。**不要**套在整块 `.rep-block` 上——它可能高于一页，硬套会把整块推到下一页并留下空白页。
- 报告页在屏幕上一次只显示一个区块，**打印时四个区块全部输出**、各另起一页（`.rep-sec{display:block!important;break-before:page}`）——否则打印只会得到当前那一个标签页。
- 段落与列表项加 `orphans/widows: 2`，避免一句话被切成两页。
- 雷达图用**两字短标签**（演绎 / 归纳 / 数量 / 约束 / 图形 / 批判 / 规划 / 风险）+ 数值标在顶点外侧，长名在 A4 上会被 viewBox 裁掉。**数值标签必须落在 viewBox 内、且与同轴维度名分开 ≥12px**（票 #27：`p2[1] < cy ? -6 : 12` 漏了 `p2[1] +`，上半圈数值全塌到画布顶边互相叠；门禁 `verify_product.py` 第 10 节）。
- 施测人报告**不含「错题回顾」**（票 #27，维护者 2026-10-24 裁定：施测人只要结果、解析与对候选人的判断；逐题解析是给考生自己复盘的）。它原本把每道错题的完整解析倒出来，打印件里是 4000+ 字一堵墙。去掉后打印件 6 页，最密一页 990 字符。
- 打印件的「每页保证」是**能定位到候选人**：每页有测评编号与页码（抬头/落款带编号），**合规声明落在报告末尾一次**，不是每页（那是票 #5 定稿的「区块落款」机制）。要每页都带合规声明，只能走 `@page` margin box（Chrome 专有），不要用 `position:fixed`。
- `print-color-adjust: exact` 只是提示不是保证；**不能依赖背景色传达信息**。

## 七、合规红线（自检脚本逐条查）

- 报告与对外文案中**不得出现**：淘汰、及格线、决定录用、有条件行、风险区、稳健区、MBTI 字母标签、智商、诊断。（合规声明原句「不作为独立的录用或淘汰依据」除外，它本身就是禁止性表述。）
- **候选人端零输出**：不显示分数、等级、短板、维度。
- 身份证：采全不存全；本机只留后 4 位 + 测评编号；结果 JSON 里只有 `idLast4`；任何载体不得出现全量或未脱敏字段。
- 测评结果不得作为录用唯一依据；不设淘汰线；五级只决定面试追问什么。

## 八、自检门（每次构建后必跑）


`verify_product.py` 的检查项：14 组色板对比度、零外链、告知卡清单 10 条、7 类红线词、96+60+40 条题面零漂移、综合评估块存在且无总分字段、无未脱敏身份证字段、五个屏在 390 CSS px 下渲染无报错、截图落在 `dist/shots/`、**胶囊内边距 ≥ 圆角半径**（第 9 节）、**雷达数值标签在画布内且不与维度名重叠**（第 10 节）。

`verify_print.py` 的检查项：A4 尺寸、四个区块各另起一页且抬头/落款各一次、文本层存在（否则需 OCR）、无空白页、各页无 undefined/NaN、**单页文字量 ≤ 1800 字符**、**每页有测评编号与页码**、**合规声明在场**、**等级词不被截断**、关键内容齐全（综合评估/短板/三项成绩/怎么用这份结果/各模块维度名/一致性检查/不得说清单）、**不含「错题回顾」**、雷达两字短标签齐全、黑白可读（五级等级词是文字、维度条有数值）。

`verify_compliance.py` 的检查项：零外链、结果 JSON 只有 `idLast4`（无全量身份字段）、存储键唯一带版本 + 旧版 4 键在清理名单里、页脚两行且五屏都渲染、断点续答与清除入口存在、**headless 实跑**（作答能写入本机存储 / 清除后旧作答与旧键都消失）、红线词零命中或仅出现在否定语境。

`verify_limit.py` 的检查项（票 #25）：**承诺 ↔ 实现**（成品里只要出现「自动交卷」，就必须同时有 `setInterval` + 题头倒计时 + 截止时刻 + 告知页的截断规则，缺一即 FAIL）、**起算点是「同意并开始测试」**、**不限时模式不挂钟**（headless）、**到点真的会自动交卷**（headless 把截止时刻设成 1.5 秒后，页面必须自己跳到完成页、留下截断标记、未答数与实际一致）、**施测人报告里能看到「限时到点自动交卷」**、**勾了限时才出现「限时与交卷说明」**、**结果 JSON 字段白名单**（`tool/version/code/name/idLast4/date/m1/m2/m3`，任何时长类字段都不许出现）。

**本机环境约束（票 #27 记的坑）**：这台机器上的 **LibreOffice 没有中文字体**，Word → PDF 会出满篇豆腐块（文本层还是好的，所以只查文本层发现不了）；**PDF 一律走 Chrome**。`w:rFonts` 的 `eastAsia` 是**属性**不是子元素，写成子元素会导致字体回退。

**打印必须真打一次**：`build.py` 只保证能构建，版式要靠
`Chrome --headless=new --print-to-pdf` 出 PDF → `pdftoppm` 转图 → 逐页看（空白页、压字、裁切、跨页断开）。只看屏幕截图会漏掉这一类问题——本轮打印实测就抓出了 4 个屏幕上看不见的缺陷。

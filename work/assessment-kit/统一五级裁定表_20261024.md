# 统一五级裁定表

> 依据：维护者 2026-10-24 11:49 裁定 ——「都改成这5个等级。如果对应的测试没有办法对应这5个等级，那就换一种在相同领域中可以被分为5个等级的测试」（原话见票 #4）
> 适用：云上文旅集团核心人才系列测试三模块
> 状态：**定稿**（票 #4）。本表是决策，不是实现；实现分工见文末「落地分工」。

## 一句话结论

三个模块的对外结论一律是同一套五级（顶尖 / 优秀 / 良好 / 合格 / 待提升），每模块给**一个总档位 + 维度明细 + 短板提示**；**第一项由「16 型画像」换成「管理行为成熟度四维五档测评」**（二极条目锚定有效端、绝对标准切档、不需要常模）；第二项与第三项沿用各自既有锚点、删掉全部淘汰语义；**全系列不设淘汰线**，五级只决定"面试追问什么"。

## 1. 五级的统一定义与措辞

| 等级 | 对外措辞 | 含义（内部口径） |
|---|---|---|
| **顶尖** | 在这一项上明显高于同类岗位的常见要求 | 高于 P90 |
| **优秀** | 达到并超过常见要求，可独立承担这类工作 | P70–P89 |
| **良好** | 满足岗位基本要求，复杂场景需要流程与复核兜底 | P45–P69 |
| **合格** | 达到门槛但余量不大，建议加强与复核 | P25–P44 |
| **待提升** | 这一项低于常见要求，需要更多支持与带教 | < P25 |

措辞沿用第三项既有的 `LEVELS`，但**删掉**「低于岗位基本认知要求」「不宜独立承担高风险判断类职责」这类隐性淘汰语义（它们等同于淘汰线）。

## 2. 三模块映射表

| 模块 | 测量构念 | 分数来源 | 档位锚点 | 对外总档 | 明细 | 短板提示 |
|---|---|---|---|---|---|---|
| **第一项**（换题后）管理行为成熟度 | 四维：互动方式 / 关注重点 / 行事依据 / 行事节奏 | 二极条目 96 题（每维 24），每题给"更有效的一端"记 1 分 | **绝对锚点**（每维 0–24，见 §2.2） | 整体档 = **最低维档** | 四维分 + 每维档 | 标出最低维 |
| **第二项** 情境测试（EQ） | 八个管理情境维度上的行为反应 | 8 维 × 12 分 → 按权重加权 0–5 | **绝对锚点**（集团既有口径：加权 ≥3.0 为达标线） | 加权分 → 五档 | 8 维分 + 各维档 | 最低维 + 一致性标记 |
| **第三项** 推理测试 | 陌生问题上的推理与判断 | 40 题难度加权 0–40 → 百分位 / T 分 | **内置参考分布**（既有） | 沿用既有 P/T 五档 | 8 维 + 错题回顾 | 最低维 |

### 2.1 第一项为什么换、换成什么

- **原设计映射不到五级**：现在是「16 型 + 四轴百分比」，没有档位维度；16 型名称（建筑师等）没有效度支撑，且贴类型标签有公平性风险。
- **换题方向**：保留**二极强制对比**的题面形式（题库在第一项独立版里，可直接复用大部分素材），但把每题改成"两端中哪一端更有效"，用**有效端计分**。
  - 不能锚定的题（两端都只是风格偏好、无优劣，如「我喜欢认识新朋友 ↔ 我更喜欢深耕熟人关系」）→ **换成可锚定题**；实在换不掉的，降级为**不计分的风格描述**（只出现在"倾向说明"里，不进分数）。
- **为什么用绝对锚点而不是常模**：本产品**目前没有预试样本**（见第三项施测说明第九节），没有参照分布就没有分位可依；所以第一项的档位必须来自题目锚定 + 专家阈值。
- **整体档取短板档**：四维里最弱的一维决定整体档。招聘上更安全，也避免"平均分掩盖单项塌陷"。
- **代价（如实记下）**：失去"16 型画像"这个直观标签及其 144 条类型文案；换来统一口径与可辩护的档位。

### 2.2 各模块档位阈值（绝对锚点，初版）

- **第一项**（每维 0–24 分）：顶尖 22–24 / 优秀 18–21 / 良好 14–17 / 合格 9–13 / 待提升 0–8
- **第二项**（加权 0–5）：顶尖 ≥4.4 / 优秀 3.8–4.39 / 良好 3.0–3.79 / 合格 2.4–2.99 / 待提升 <2.4
  （2.4 与 3.0 沿用集团既有口径，3.8 / 4.4 为新增上下锚）
- **第三项**：沿用既有 —— 顶尖 P90+（T≥63）/ 优秀 P70–89（T 55–62）/ 良好 P45–69（T 48–54）/ 合格 P25–44（T 42–47）/ 待提升 <P25（T<42）

### 2.3 三个模块的分数**不可跨模块比大小**

第二项是绝对加权分、第三项是内置参考分布的分位、第一项是绝对锚点分 —— 三者口径不同，**只能并排列档位，不能合成一个总分**。所以总报告只并排三档 + 各自的短板提示（与地图口径第 4 条一致）。

## 3. 对外报几个维度

| 场景 | 报什么 |
|---|---|
| **候选人端** | **什么都不报**：只有完成页 + 回传引导（地图口径 2 + 告知卡清单 §2.4 红线） |

| **教练版**（内部带教材料） | 全维度 + 逐维度练习动作 |

## 5. 没有淘汰线之后，HR 的动作

**一句话流程**：测评 → 只产出「追问清单」→ 面试按清单取证 → 录用决策用多源证据 → 记录冲突与理由。

| 事项 | 规定 |
|---|---|
| 测评在录用决策中的位置 | **不作评分项**，只作追问线索；同一岗位对所有候选人用同一套题、同一权重、同一阈值 |
| 五级怎么用 | 每级对应固定的追问方向：顶尖 / 优秀 → 验证复杂度；良好 → 验证流程依赖；合格 → 验证带教成本；待提升 → 验证在有支持时能否改善 |
| 书面反馈 | 只给 4 个合并维度 + 总档 + 辅助参考声明，不出现五级以外的淘汰措辞 |
| 冲突处理 | 测评与面试 / 工作样本冲突时**以面试与样本为主**，并在记录里写明冲突原因（沿用第三项施测说明第七节） |
| 留痕 | 阈值、判定规则、每级追问方向写进留痕文件，与候选人记录一并归档 |
| 留存 | ≤ 1 年，到期删除或匿名化（告知卡清单 §4） |

## 6. 上线前必须做的校准

- **第一项**：锚定端双人独立标注 + 分歧仲裁；30–50 份内部样本试测；α 与分半信度；四维与岗位胜任力的对应关系复核（EQ 简报要求的"岗位胜任力映射"）。
- **第二、三项**：用首批内部样本把绝对锚点与参照分布对齐，形成两套口径（初版绝对锚点 / 稳态参照分布），**报告里标注当前用的是哪一套**。
- 阈值一旦定版写进留痕文件，**之后不得按人调阈值**。

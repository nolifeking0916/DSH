**猎聘背调基本流程**（猎聘联合第三方背调机构提供的服务，企业 HR 在平台一键发起）：

| 步骤 | 内容 |
|---|---|
| ① 企业下单 | HR 在平台选定套餐深度（基础 / 标准 / 深度），发起背调 |
| ② 候选人授权 | 候选人签电子授权书，明确目的、范围、信息类型——**无授权不启动**，这是法律红线 |
| ③ 信息收集 | 候选人提交身份信息、学历证明、工作履历、证明人（上级 / HR / 同事）联系方式 |
| ④ 基础核验 | 公安系统比对身份；学信网 / 教育部认证验学历；职业资格证书发证机关核验 |
| ⑤ 履历访谈 | 联系前雇主 HR 或直属上级做电话访谈，核任职时间、职位、离职原因、工作表现 |
| ⑥ 风险筛查 | 法院诉讼、失信被执行人、金融黑名单、犯罪记录等公开数据库比对 |
| ⑦ 深度加项 | 高管 / 核心岗位：家访或实地走访、行业口碑侧面打听、竞业限制排查 |
| ⑧ 交叉验证 | 多来源信息比对，疑点反馈候选人解释（给申诉机会，避免误伤和官司） |
| ⑨ 出报告 | 生成报告交付 HR，平台可实时查看进度 |

**时效与费用参考**

| 套餐 | 内容 | 周期 | 参考价 |
|---|---|---|---|
| 基础 | 身份、学历 | 最快 24 小时 | 约 100–200 元/人 |
| 标准 | 加履历、不良记录 | 2–3 个工作日 | 中等 |
| 深度 | 加信用、犯罪、高管项 | 5–7 个工作日 | 约 500–1000 元/人 |

**HR 侧合规要点**（用人方发起时最易踩坑的几处）：

- 授权书必须写明调查目的、范围、信息类型、使用期限，电子签有效
- 不得查婚育、宗教、政治面貌等与工作无关的隐私；征信、犯罪记录需单独授权或法定要求
- 全程不得向前雇主透露候选人应聘的新雇主信息
- 未入职候选人的背调信息应在合理期限后删除或匿名化
- 学历造假、犯罪记录属硬性风险通常一票否决；任职时间 1–3 个月误差一般结合岗位综合评估
